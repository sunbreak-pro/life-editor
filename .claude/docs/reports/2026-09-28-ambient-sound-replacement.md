# 環境音プリセット 5 本の差し替え（#1793 の残り）

> 2026-09-28 / chat-main（worktree `ambient-sounds`）/ Issue #1793 の残作業「音源の差し替え」の記録。前回の実測は [`2026-09-21-ambient-sound-asset-measurement.md`](./2026-09-21-ambient-sound-asset-measurement.md)、再生側の修正は PR #1922。

## 結論

**5 本を新しい録音から作り直し、2026-09-21 に決めた差し替え条件をすべて満たしました。** 両端の無音は 0 ms で、帯域は 20.5 kHz まで残っています。1 本は 110〜120 秒あり、音量は 5 本とも -28 dBFS に揃っています。バケットへのアップロードはこうだいさんの作業で、手順は `supabase/README.md` の「Ambient sounds」節にあります。

Chromium の `<audio loop>` には、ファイルと関係なく巻き戻しのたびに約 10 ms の隙間が残ります。WAV と FLAC でも同じ 10 ms が出ました。これを消すには再生コードを変える必要があるので、今回は手を付けていません。

## 素材

どの録音も CC0 か Public Domain Mark です。バケットは公開なので、再配布を禁じるライセンスの素材は使えません。一覧とダウンロード元は `supabase/scripts/ambient-sources.json` にあります。

| プリセット | 録音                                                                | ライセンス | 使った区間       |
| ---------- | ------------------------------------------------------------------- | ---------- | ---------------- |
| rain       | Dharamshala Rain（AugustSandberg / Freesound 508527）               | CC0 1.0    | 202 s から 120 s |
| wind       | Howling Wind, Troon, Cornwall（radio aporee 30717）                 | PDM 1.0    | 175 s から 120 s |
| ocean      | Gotska Sandön – waves breaking（Melissa Pons / radio aporee 33898） | PDM 1.0    | 4 s から 115 s   |
| birds      | Šumarice summer forest（danilocrni / radio aporee 54242）           | PDM 1.0    | 64 s から 110 s  |
| fire       | Campfire 02（HECKFRICKER / Freesound 729396）                       | CC0 1.0    | 16 s から 110 s  |

区間は、1 秒ごとの音量の揺れがいちばん小さく、突発音の少ない場所を数値で選びました。Freesound の元ファイルはログインしないと取れないため、2 本は Internet Archive にある転載から取りました。転載が試聴用の MP3 ではなく元の WAV であることは、長さ・形式・サイズの一致で確かめています。

## 作り方

`supabase/scripts/ambient-loops.mjs build` は、素材ごとに次の順で処理します。

1. 区間を 48 kHz ステレオで切り出します。fire だけは先にリミッターを通します。はぜる音が背景より 40 dB 大きく、そのまま音量を揃えると背景がほとんど聞こえなくなるためです。
2. 区間の後ろ 3 秒を頭に重ねます（等パワーのクロスフェード）。最後のサンプルが最初のサンプルにそのままつながります。
3. RMS を -28 dBFS に揃えます。-28 は差し替え前の 5 本の中央付近で、差し替えても急に大きく聞こえないようにしました。ピークが -1 dBFS を超えるときは、ゲインのほうを下げます。
4. LAME の CBR 320 kbps で 1 回だけエンコードし、LAME タグを残します。

256 kbps と VBR V0 も試しましたが、どちらも LAME が 16 kHz より上の小さな成分を自分で落としました。ocean は元の WAV に 21 kHz まで成分があるのに、256 kbps では 16 kHz に壁が立ちます。前回の報告は 16 kHz の壁を「低ビットレート素材の再利用」の証拠としましたが、エンコーダの設定だけでも同じ形になります。

| birds.mp3 | 110 s | -28.0 | -5.0   | -13.4 dB                  | 0/0 ms     | 21/15 ms         | 0.66         |

差し替え前の 5 本は、同じ計測で 18〜20 kHz が -60〜-101 dB、両端の無音が 20〜132 ms でした。継ぎ目の段差は、隣り合うサンプルの平均的な差を 1 としたときの比です。1 前後なら、継ぎ目がほかの場所と区別できません。

1 秒ごとの音量で目立つ出来事も探しました。rain は揺れが 1.5 dB の範囲に収まっています。wind は 38〜40 s に 3 秒ほどの突風があり、中央値より 5 dB 大きくなります。ほかの 3 本に 1 秒単位の突出はありません。

## ブラウザでの継ぎ目

Chromium 153 で `<audio loop>` を `createMediaElementSource` に通し、4 秒のループを 13 秒録音しました。1 ms ごとの音量が -60 dBFS を下回った長さを測っています。

| ファイル                            | 巻き戻しごとの無音 |
| ----------------------------------- | ------------------ |
| MP3（LAME タグあり = 今回の作り方） | 10 ms              |
| MP3（タグなし = 差し替え前と同じ）  | 36〜39 ms          |
| WAV                                 | 10 ms              |
| FLAC                                | 10 ms              |

Chromium は LAME タグを読んでエンコーダの詰め物を取り除きます。残る 10 ms は形式によらず同じなので、`<audio loop>` の巻き戻しそのものの遅れです。Safari と Firefox は測っていません。

## 確かめていないこと

- **耳での確認**: 数値では人の声や車の音を見分けられません。鳥の音源は昼の森で虫の声が強めです。風の音源は電線を抜ける風で、笛のような音が混ざる可能性があります。
- **Safari（iOS / macOS）での継ぎ目**: Windows 機では測れません。
- **再生コード側の 10 ms**: 消すには、2 本の要素を交互に重ねるか、Web Audio の `AudioBufferSourceNode` の `loop` に移す必要があります。どちらも `AudioContext.tsx` の変更になるので、別の Issue で扱います。
