# CLAUDE.md の 2 層構造 — 航法 / 目的への振り分け表

> **これは何か**: `.claude/CLAUDE.md` を **航法（Navigation）/ 目的（Why）** の 2 層に再編するための振り分け表と、各記述の移送先。
> **親計画**: [`plans/2026-08-04-context-cost-reduction-harness.md`](./plans/2026-08-04-context-cost-reduction-harness.md) Phase 2（枠づくり）。
> **計測の裏づけ**: [`../reports/2026-08-06-context-fixed-cost-baseline.md`](../reports/2026-08-06-context-fixed-cost-baseline.md)。
> **本書は枠であって、移送そのものではない。** 実際の移送は Phase 3（移行完了後・1 PR = 1 項目）。本書が先に決めるのは「どこへ移すか」と「移送先が実在するか」だけ。

## 1. なぜ 2 層か

CLAUDE.md は今、事実・手順・禁止・経緯が混ざっている。**引っ越しの荷造りで「日用品」「季節物」「思い出の品」を同じ段ボールに入れた状態**で、毎朝そのひと箱を全部開けている。

2 層に分けるのは、開ける箱を減らすためではなく、**毎回開ける箱に何を入れるかの基準を持つため**。基準が無いと、方針だけ書いても数か月で元に戻る（親計画 §Context-2）。

| 層                  | 中身                                                    | 判定式                                             |
| ------------------- | ------------------------------------------------------- | -------------------------------------------------- |
| **A. 航法**（事実） | 構造・参照先マップ・検証コマンド・踏むと壊れる罠        | 消したら Claude が間違う **かつ** 毎回必要         |
| **B. 目的**（基準） | Vision・Non-Goals・優先順位                             | 判断を委ねるために要る基準                         |
| （層外）            | 手順 → skill / 規約 → rules / 禁止 → 機械 / 経緯 → docs | 毎回は必要ない。**移送先が確保できたものだけ移す** |

**削減量は目標にしない。** 基準は「移送先があるものは移す」だけ（親計画 確定事項）。移送先が無く作る先も決まらないものは残す。

## 4. 実体の無い禁止の棚卸し

親計画 §2.3: **実体が無い禁止は、実体を作ってから文章を削る**。文章だけの禁止を消すと、守らせるものが何も残らない。

| `gh pr merge` を Claude がしない（P-001）  | `settings.json` `permissions.ask`              | ✅ 実体あり |

| 色のハードコード（`lumen-*` トークン必須） | なし                                           | ⬜ 未実体   |
| `.claude/` 直下にプラン `.md` を置かない   | なし（`scripts/docs-lint.sh` に 1 行で足せる） | ⬜ 未実体   |

**⬜ の 7 件は Phase 3 でも文章のまま残す**（実体を作るのが先）。実体づくりを本 Phase でやらないのは、hook / lint ルールの追加が**全セッション・全 PR に即座に効く**ため、移送と同じ PR に入れて 1 つずつ検証したいから。**「削るために実体を作る」であって「実体を作るために削る」ではない**ので、実体づくり自体が独り歩きしないよう Phase 3 の各 PR に紐づける。

## 6. Phase 3 の進め方（移送）

1. **1 PR = 1 項目**。上の表の 1 行ずつ
2. **消失ゼロの検証**: 削除した記述が移送先ファイルに存在することを、PR 本文に grep 結果で示す
3. **再測定**: [`scripts/context-cost-measure.mjs`](../../scripts/context-cost-measure.mjs) を移送の前後で回し、計測結果ファイルに 1 行追記する
4. **ゲート**: `LC_ALL=C bash scripts/docs-lint.sh` + CLAUDE.md §7.1 の lint / build / test
5. **着手条件**: 移行（Electron + Capacitor + Web + Supabase）完了。移行中は移送先自体が動くため開けない（親計画 Risks）
