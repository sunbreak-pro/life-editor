# 2 通目以降のプロンプト — 画面を足す・ずれを直す・微調整する

> 最初のプロンプト（`10-prompt-initial.md`）で外枠と朝刊ができたあと、同じ Claude Design のプロジェクトで続けて使います。
> 各枠の中身を raw テキストのままコピーします。`<…>` の部分だけ書き換えてください。
> 1 通に 1 画面が目安です。2 画面を 1 通に詰めると、後半の画面の再現が粗くなります。

## A. 画面を足す（1 画面ずつ・この順番）

順番は、ほかの画面から部品を借りる関係で決めています。予定の右パネルの「今日の Todo」はつながりでも使い、素材のエディタは Daily と朝刊でも使います。

1. 予定（Schedule）
2. 素材（Materials のノート / デイリー）
3. つながり（Connect のタグ / 目標と Todo）
4. 集中（Work）
5. 分析（Analytics）
6. 設定（Settings。ゴミ箱・ヘルプのダイアログ・プロフィールを含む）
7. サインイン画面（Auth。ヘルプのダイアログを含む）

```markdown
# 続き: 「<画面名>」を足してください

添付の `01-screens.md` の「<画面名>」の節と、スクリーンショット（ファイル名に `<画面の英語名>` を含むもの）のとおりに、今の画面を再現してください。外枠・試作パネル・これまでに作った画面は変えないでください。

- `02-interactions.md` の「<画面名>」の行を、すべて動くようにしてください。
- 作成・編集・削除は、最初のメッセージの決まりどおりです（フォームまでは開き、保存は「試作のため保存しません」のトーストで閉じる）。
- 状態の切り替え（データあり / 空 / 読み込み中 / エラー）を、この画面にも効かせてください。
- Desktop と Mobile の両方を作ってください。Mobile で出さないものは `01-screens.md` に書いてあります。

最後に、再現できなかったところ・推測で埋めたところの一覧を返してください。
```

## B. ずれを直す（再現の 2 回目以降）

こうだいさんが試作と実画面を見比べて、ずれを見つけたときに使います。Claude Code に頼めば、試作のスクリーンショットと実画面を並べてずれの表を作ります（`README.md` の「出来を比べる」）。その表を下の枠に貼ります。

```markdown
# 直してください: 「<画面名>」の今の画面とのずれ

実画面と試作を比べて、次のずれが見つかりました。実画面のほうに合わせてください。ほかの部分は変えないでください。

| 場所                       | 実画面                                          | 試作                   |
| -------------------------- | ----------------------------------------------- | ---------------------- |
| <例: サイドバーの行の高さ> | <例: 40px（2.25rem）>                           | <例: 36px>             |
| <例: 見出し行の右端の並び> | <例: 検索欄 → 元に戻す / やり直す → パネル開閉> | <例: パネル開閉が左端> |

実画面のスクリーンショットを添付します: `<ファイル名>`
```

## C. 微調整する（再現ができてから）

ここからが本来の目的です。言葉で頼む方法と、試作パネルのつまみで直接いじる方法があります。つまみで決めた値は「値を書き出す」で JSON にして、そのまま Claude Code に渡せます。

```markdown
# 微調整: 「<画面名>」の <余白 / 文字の大きさ / 配置>

今の再現を出発点に、次の方向で調整した案を 2〜3 個ください。案ごとに、試作パネルの「値を書き出す」と同じ形で、変えた値の JSON を添えてください。

- 良くしたいこと: <例: 一覧の行が詰まって見える。1 行ずつ読みやすくしたい>
- 変えてよいもの: <例: 行の高さ・行の間・文字の段>
- 変えてはいけないもの: 色（tokens.css の値以外を使わない）・部品の種類・画面の構成・Mobile の 44px のタップ領域

余白は 4 / 8 / 12 / 16 / 24px の段から選んでください。段に無い値が必要なら、その値と理由を「段の追加の提案」として別に書いてください。
```

## D. 調整した値を持ち帰る

- 試作パネルの「値を書き出す」で出た JSON を、Claude Code のチャットに貼って「この値を実装に戻して」と頼みます。
- 値をコードのどの書き方（`lumen-*` トークン・Tailwind のクラス）に置き換えるかの対応表は Issue #2154 で決めます。対応表ができるまでは、Claude Code が JSON を受け取って変更の案を出し、こうだいさんが確認してから直します。
