# 試作で動いてほしい操作の一覧（Claude Design に渡す資料 3/4）

> データの作成・編集・削除（保存）以外の操作を、画面ごとに並べました。Claude Design には「この表の行がすべて動くこと」を受け入れの条件として渡します。こうだいさんは、試作を触りながら「確認」の列に印を付けます。
> 「幅」の列は D = Desktop、M = Mobile、DM = 両方です。保存の操作は最後の節にまとめ、フォームまで開いて保存はトーストで止める扱いにします。
