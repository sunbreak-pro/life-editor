> **[保存]** と付けた操作は、データの作成・編集・削除です。試作ではフォームまで開き、確定すると「試作のため保存しません」のトーストを出して閉じます。

## 0. 全画面に共通のもの

### キーボードの近道

設定画面で割り当てを変えられます。「Mod」は Windows の Ctrl、Mac の ⌘ です。

| キー                  | 名前                  | 結果                                                             |
| --------------------- | --------------------- | ---------------------------------------------------------------- |
| Mod+,                 | 設定を開く            | 設定へ移動                                                       |
| n（入力中は効かない） | 新規 Todo を作成      | 予定へ移動し、右パネルの Todo タブと「Todo の追加」のダイアログを開く |
| Mod+1                 | Todo へ移動           | 予定へ移動し、右パネルを Todo タブで開く                         |
| Mod+2                 | デイリーへ移動        | 素材のデイリー                                                   |
| Mod+3                 | ノートへ移動          | 素材のノート                                                     |
| Mod+4                 | スケジュールへ移動    | 予定                                                             |
| Mod+5                 | つながりへ移動        | つながりのタグ                                                   |
| Mod+Z / Mod+Shift+Z   | 元に戻す / やり直し   | 入力中は効かない。試作では押せる見た目と、戻すものが無いときの無効表示だけ |

画面の中だけで効くキーもあります。セグメントコントロールは矢印キーで端から端へ回り込み、詳細パネルの幅のハンドルは ← → で 16px ずつ変わります。Esc はポップオーバー・メニュー・ダイアログ・引き出しを閉じます。

### トースト

- 種類は info / success / warning / danger の 4 つです。左端に 3px の色の帯があり、danger は AlertCircle のアイコン、ほかは色の点を出します。
- Desktop は右下、Mobile は下部タブバーの上に出ます。既定は 4 秒で消え、× で閉じられます。朝刊の保存の失敗は 8 秒、予定のリマインダーは 10 秒出ます。
- 文言の例: 「元に戻しました: {{label}}」「「{{title}}」とのリンクを外しました。ヘッダーの「元に戻す」で戻せます。」

### 画面の上の帯

すべての上に、状態に応じて次の帯が出ます。試作パネルの状態の切り替えで確かめられるようにします。

- **オフライン**（warning、WifiOff）: 「オフライン — 見るだけです。新しい Todo とデイリーの編集、新しいノート、ピン留めしたノートの編集だけはこの端末に残し、回線が戻ると送信します。ほかの変更には接続が必要です。」
- **送信待ち**（info。オンラインで送っていない変更があるとき）: 「送信待ちの変更が {{n}} 件あります。」
- **送信の失敗**（danger）: 「送信できなかった変更が {{n}} 件あります…」と、「本文をコピー」「この端末から削除」のボタン。
- **アプリの更新**（info。オフラインの帯の下）: 「新しいバージョンがあります。区切りのよいときに再読み込みしてください。」と「再読み込み」。

### そのほか

- **初めて開いた画面**: その画面を初めて開いたときだけ、下から浮き上がる入りのアニメーションが付きます（250ms、ease-out）。
- **未保存のまま離れる**: 「保存していない変更があります。破棄して閉じますか？」（キャンセル / 破棄）の確認が出ます。
- **画面のエラー**: 画面ごとに「このセクションを表示できませんでした」と 再試行 / 再読み込み、アプリ全体では「問題が発生しました」を出します。
- **アイコン**: ナビは Sunrise / Clock / Library / Tags（18px）。サイドバーは PanelLeftClose / PanelLeftOpen / Settings（アカウントの行の歯車）/ LogOut / Terminal（Claude Code を起動）、見出し行は Undo2 / Redo2 / PanelRightOpen / PanelRightClose、見出し行のタブは Sunrise・Sunset（朝刊・夕刊）/ FileText・CalendarDays（ノート・デイリー）/ Tag・Target（タグ・目標と Todo）、Mobile のハンバーガーは枠付きの PanelRight、その他は MoreHorizontal です。

## 1. アプリの外枠

### Desktop

- **サイドバー**（幅 `w-60`、折りたたむと `w-16`。幅は 200ms の動きを付けて変わり、折りたたみの状態は覚えておく）
  - 上端: 24px の正方形に accent 色の「L」、「Life Editor」、折りたたみボタン（サイドバーを折りたたむ / サイドバーを展開）。
  - ナビ: 朝刊・予定・素材・つながりの 4 行だけです。設定の行はありません。
  - 選択中の行は accent-subtle の地に accent の文字で、左端に 3px の accent の線が付きます。折りたたみ中はアイコンだけで、ホバーで名前のツールチップが出ます。
  - フッター: Desktop アプリでは先頭に「Claude Code を起動」（Terminal）の行が出ます。続いてアカウントの行です。見える文字は表示名で、未設定ならメールアドレスです。右端に 14px の歯車が付き、ホバーでメールアドレスが出ます。押すと設定のプロフィールを開き、設定を開いている間はこの行が選択の見た目になります。その右にサインアウトのアイコンがあります。折りたたみ中は、歯車のボタンとその下のサインアウトだけです。
  - サインアウトを押すと、右に確認の小窓「サインアウトしますか？」（キャンセル / サインアウト（danger））が出ます。送信待ちの変更があるときは、文が長い注意に変わります。
- **見出し行**
  - 左: 画面名（前にサイドバーと同じアイコン）、またはその画面のタブ。タブは下線型で、頭にアイコンが付きます。選択中は accent の 2px の下線と text-primary の太字、非選択は text-secondary です。
  - 右（左から）: 元に戻す・やり直すの枠付きのアイコンボタン、詳細パネルの開閉。開閉ボタンの名前は、ふつうは「詳細を開く / 詳細を閉じる」で、ノートでは「ノート一覧を開く / 閉じる」、デイリーでは「カレンダーを開く / 閉じる」です。
- **見出し行のタブ**

| 画面       | タブ                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 朝刊       | 朝刊 / 夕刊（17 時以降と、日付が変わる時刻より前の深夜は夕刊で開く）           |
| 素材       | ノート / デイリー。それぞれに件数のバッジ（0 件のときは出ない）                |
| つながり   | タグ / 目標と Todo                                                             |
| 予定・設定 | タブなし。アイコンと画面名だけ                                                 |

### Mobile

- **上端の帯**: [ハンバーガー] [セグメントコントロールか画面名] [元に戻す][やり直す] の並びです。朝刊・素材・つながりはセグメントコントロール、予定と設定は画面名です。帯はどの画面でも枠の上端に固定され、本文をスクロールしても動きません。やり直すの右には、画面ごとのボタンが入ります（今はノートの「＋」だけ）。
- **下部タブバー**: 朝刊・予定・素材・つながりの 4 つと「その他」。選択中は accent の文字です。キーボードが出ている間は隠れます。
- **その他シート**（題「その他」）: 先に「クイック操作」として元に戻す・やり直す。区切りのあとに、設定。
- **最初に開く画面**: 設定の既定は「前回の続きから開く」です。初めて開いたときと、前回の記録が無いときは朝刊です。

## 3. 詳細パネル（Desktop）と左の引き出し（Mobile）

- **Desktop**: 見出し行の下で、メイン領域の右に押し込み式で入ります。不透明な `bg-subsidebar` に左の border です。見出しの行と閉じるボタンはなく、見出し行の開閉ボタンで閉じます。幅は既定 320px で、240〜560px の範囲で変えられ、幅だけを覚えておきます。ただし、メイン領域から 520px を引いた幅より広くはなりません。左端の 6px の帯がハンドルで、カーソルは col-resize、ホバーで accent の 30% の色になります。メイン領域が 320px を割りそうなときは、サイドバーを表示の上だけ自動で折りたたみます。
- **Mobile**: 幅 360px（画面幅の 85% まで）の左の引き出しです。見出しの行はなく、引き出しの右端の外側に 44px の丸い ×（詳細を閉じる）が浮きます。開くとこの × にフォーカスが入ります。Esc・幕のタップ・×・左へのスワイプで閉じ、ハンバーガーか画面の左端から右へのスワイプで開きます。
- **中身**: 画面ごとに中身を差し込みます。何も無い画面は「表示する詳細はありません」。開閉の状態は画面を移っても保ちますが、再読み込みすると閉じた状態に戻ります。Desktop では、ノートと設定を開いたときに自動で開きます。つながりはアイテムを選んだとき、目標と Todo は目標を選んだときに開きます。

## 4. 朝刊（briefing）

紙面は中央に 1 列、最大幅 `max-w-2xl`、下に `pb-16` の余白があります。

### 朝刊タブ（上から順に）

1. **題字**: serif で字間を広げた「LIFE EDITOR 朝刊」、日付の行（例: 2026年11月25日水曜日）、下に二重線。
2. **ゆうべの自分から**: 朱色の小さなラベルと、serif・xl の 1 行。無い日は Sunrise のアイコンと「まだありません。夕刊の『明日の自分へ』で書くと、ここに出ます。」
3. **昨日へのひとこと**（Claude が書いた日だけ）: 朱の縦線付きの見出し、Sparkles のアイコン付きの「Claude ・ 朝刊セクションより」の丸いバッジ、琥珀の薄塗りに左の線が付いた段落のカード。
4. **これからの目標**: 見出しの右端に「目標」のボタンがあります。
   - 今年 / 今月 / 今週 を 1 行ずつ並べます。行は、期間の印、最初の目標の名前、「その他 {{count}}」、期間の進み具合の棒と完了数/全体です。目標の無い期間は「未設定」のボタンになります。
   - 終わった期間の目標があると、行の上に「終わった期間の目標が {{count}} 件あります」の 1 行だけが出ます。
   - Mobile では、棒と件数を外して、目標の名前と「その他 N」だけにします。
   - 「目標」のボタンを押すと、目標パネル（題「目標」。Desktop は中央のダイアログ、Mobile は下からのシート）が開きます。パネルの中は次の 3 つの表示を入れ替えます。
     - 一覧: 「終わった期間の目標」の確認カード（「残り {{count}} 件」、持ち越す / やめる / 達成にする / あとで聞く **[保存]**）、期間ごとの目標と「Todo をつなぐ」、目標が無いときの「今週の目標を立てましょう」、追加欄（見出し「目標を立てる」、入力の例「届きたいところを書きます」、「追加」**[保存]**）、「目標と Todo で開く」（つながりの「目標と Todo」タブへ移動）。
     - 1 つの目標の詳細: つながりの目標の詳細と同じ中身で、上に「目標の一覧へ戻る」が付きます。
     - Todo をつなぐ: 検索欄とチェックボックスの一覧（つなぐ確定は **[保存]**）。
5. **今日のスケジュール**: 時刻の表です。
   - 見出しの右に「表示する列」の 予定 / Todo の切り替えがあります。Desktop は片方の列を隠せますが、両方は隠せません。Mobile は 1 列ずつ出し、最初は予定の列です。
   - 表の上に終日の帯（Sun のアイコン・「終日」・チップ）があります。4 件以上のときは 2 件だけ出し、「他 N 件」/「閉じる」で開閉します。
   - 表の列は 時刻 / 予定 / Todo で、列の見出しに ＋（「予定を追加」/「Todo を追加」）があります **[保存]**。
   - 行は時刻ごとにまとめ、時刻の無いものは最後の「時間なし」の行に入ります。今の時刻の朱の線が行の間に入ります。
   - 予定のセル: カレンダーのアイコン、題、繰り返しなら「ルーチン」のタグ、進行中なら「進行中」の印、その下にタグの行（4 個以上は 2 個と「他 N 件」）。終わった予定は薄い文字になります。
   - Todo のセル: 状態のチェック（未着手 / 完了。1 タップの切り替え）、題、Target のアイコン付きの目標の名前、◈ 付きのリンク先の名前、タグの行。
   - 題を押すと、予定の画面へは移らず、その場で編集パネルが開きます。パネルの中に「予定で見る」があります。行ごとの「編集」「削除」のボタンはありません。
   - 空のとき: 「今日のスケジュールはありません」。Todo の列だけのときは「今日の Todo はありません」。

読み込み中は 8 行のスケルトンです。

### 夕刊タブ（上から順に）

1. 題字「LIFE EDITOR 夕刊」、日付の行、「夕刊 第 N 号 · N 日連続」（連続が 0 日なら「夕刊 第 N 号」だけ）。
2. 今日の気分: 5 つの★（1 タップの切り替え。ホバーで何個目まで光るかを出す）。
3. 今日進んだ目標（例: 「企画書を通す 2/4 → 3/4」）。無いときは「今日進んだ目標はありません」。
4. 今日の出来事: 「予定 N · Todo N」の要約（Todo が 0 件なら「予定 N」だけ）と、行ごとの「一言」のボタン。
5. 一日の締めくくり: 振り返りのエディタ。空なら「今日のふり返りを書く」の呼びかけ。打ったあとは「保存済み / 未保存」が付きます。
6. 明日の予定に置く: Todo の題・つながった目標の名前・時刻（任意）と「明日に置く」ボタンの行 **[保存]**。
7. 明日の自分へ: 1 行の入力欄（入力の例「明日いちばん進めたいことを一行で…」）。
8. 紙面の最後に「Daily に移動」のボタン。

### 詳細パネル

- **朝刊タブ**: 「きのうまでの自分」（Todo 完了トレンドのグラフ）と、その下に「持ち越し」。持ち越しの行は「N日目」・チェックボックス・題と、右の「編集」のボタンです。連続日数と「今日の Todo」は朝刊のパネルにありません。
- **夕刊タブ**: 「今日の Todo」（状態付き。「今日の予定に追加」を含む）、「残りの Todo」、「今後の予定」（「明日」のチップ、「この日の予定へ移動」「編集」「繰り返しを見る」）。

### Mobile

上端の帯（ハンバーガー + 朝刊 | 夕刊 + 元に戻す・やり直す）は、ほかの画面と同じく枠の上端に固定されます。目標の要約は名前だけ、今日のスケジュールは 1 列ずつになります。ほかは Desktop と同じです。

## 5. 予定（schedule）

### Desktop

- **見出し行**: タブはなく、Clock のアイコンと「予定」です。
- **ツールバー**: 左に [今日] [‹ 前へ] [› 次へ] と期間の表示が並びます。期間は、週なら「11/22 – 11/28」、月なら「2026年11月」です。右には次のものが並びます。
  - 祝日のトグル（Flag）。ラベルは「祝日を隠す」で、隠しているときは「祝日 N 件を非表示」になり、accent の押下の見た目になります。
  - 繰り返しのトグル（Repeat）。ラベルは「繰り返しを隠す」と「繰り返し N 件を非表示」です。
  - 週 / 月のセグメント。
  - 絞り込みボタン（ListFilter、「タグで絞り込む」）。効いているときは名前が「タグ N 件で絞り込み中」になり、右下に件数のバッジが出ます。
  - accent の主ボタン「＋ 予定を追加」。
  - 表示領域の幅が 55.5rem 未満だと、祝日のトグルはアイコンだけになります。48rem 未満では、繰り返しのトグルの「N 件を非表示」が数字だけに縮みます。
- **レンズの行**: 保存したタググループがあるときは、「グループで絞り込む」のラベルと、「グループ名 件数」のチップ（例: 「プライベート 1」）が並びます。絞り込み中は「N 件を非表示」と、文字のリンクの「すべて表示」が足されます。グループが無くても、絞り込みパネルでタグを選んでいれば、ラベルとチップの無い行が出ます。
- **週ビュー**: 7 日の列と終日の行があり、0〜24 時で 1 時間 48px です。開くと、今の時刻の 1.5 時間上から見えるようにスクロールし、「今日」を押すとそこへ戻ります。0 時の時刻ラベルは空欄です。今の時刻に朱の線と点を引き、今日の列を accent-subtle の地で強調します。
  - ブロックは種類で色が分かれます（予定 = 紫、繰り返し = 藍、Todo = 青）。左の線はタグの色です。繰り返しには Repeat、Todo には CheckSquare のアイコンが題の前に付きます。
  - 時間の重なった予定は横に並べます。祝日は終日の行に danger の薄い地のチップで出ます。
  - 空いた枠のクリック（30 分単位）はアイテム追加を開きます **[保存]**。ブロックのドラッグでの移動・伸縮・終日の行へのドロップは **[保存]** です。
- **月ビュー**: 42 マスの月です。
  - 予定はチップで並べます。チップは、種類のアイコン（Calendar / CheckSquare / Repeat）・種類の薄い色の地・左の 3px の線（タグの色。タグが無ければ種類の色）・題です。1 マスに 5 件までで、6 件目からは「他 N 件」にまとめます。
  - マスの右上の ＋（「{{date}} に追加」）がその日の追加を開きます。＋ はホバーかフォーカスのときだけ見えます。
  - 「他 N 件」は、マスの横に幅 248px のパネル（「{{date}} の残りの予定」）を開きます。×・Esc・外側のクリック・スクロールで閉じ、行を押すと吹き出しが開きます。
- **アイテムを 1 回クリック**: カーソルの近くに幅 520px の 2 列の吹き出しが出ます。右クリックでも同じ吹き出しが出ます。Esc か外側のクリックで閉じます。
  - 左の要約: 種類のバッジ（予定 / 繰り返し）、題、「11月24日（火）・09:50–17:50」、タグのチップ、メモの 1 行。
  - 右の操作: 「複製（タグごと）」「複製（タグなし）」（タグの無い予定は「複製」だけ）、「Todo に変換」、「削除」（danger）。
  - 下: 全幅の「詳細を編集」。
  - 要約をダブルクリックするか、フォーカスして Enter を押すと、その場で題・日付・開始 / 終了を直せます（「保存」「キャンセル」）。繰り返しの回は日付を直せず、終日の予定には時刻がありません。
  - Todo のチップの吹き出しは、要約（バッジ Todo・タグ・メモ）と「予定に変換」「Todo を削除」「詳細を編集」です。その場で直せるのは題と開始時刻です。
  - 祝日のチップの吹き出しは、バッジ「祝日」と「祝日を隠す」だけです。
  - どの操作も、確定は **[保存]** です。
- **重ねて開くもの**
  - アイテム追加（題「アイテムを追加」、右上に ×）: 種類 予定 / Todo、追加方法 新規作成 / 既存から選ぶ、タイトル、日付、開始 / 終了、終日（丸いチェック）、繰り返し（予定のときだけ。なし / 毎日 / 曜日 / N日ごと）、「タグ ＋タグを追加」、「ノートを添付」。フッターは「キャンセル」「追加して詳細へ」「追加」です。
    - 「既存から選ぶ」は種類で変わります。予定は「予定を検索」で既存の予定を選び、その複製を追加します。Todo は未配置の Todo を「Todo を検索」で選び、ボタンが「この時間に配置」「配置して詳細へ」に変わります。
    - 「ノートを添付」は「ノートをどうしますか」と聞き、新規作成 / 既存から選ぶ / やめる を出します。「既存から選ぶ」は「ノートを選ぶ」の一覧をダイアログの横に開き、ダイアログが 860px に広がります。
  - 予定のエディタ: 画面中央の 2 列のモーダルです。見える見出しと × はなく、キャンセル・Esc・幕のクリックで閉じます。保存ボタンは、変更があるまで押せません。
    - 左の列: タイトル、日付、終日、開始 / 終了、繰り返し。繰り返しの回では、説明文、曜日の丸ボタン、「終了日」（「空欄なら終わりなく繰り返します」）、「この日はスキップ」が出ます。
    - 右の列（上から）: タグを付ける範囲「すべての回 / この回のみ」（繰り返しのときだけ）、タグと「ノートを添付」、「カレンダーで使う色」（「「X」タグの色で表示」「タグの色を変える」とタグごとのラジオ）、メモ、リマインダー（通知しない / 5・10・15・30・60 分前。終日のときは隠れる）。
    - 下: 全幅の「Todo に変換」と、フッターの「削除」（左端）「キャンセル」「保存」。
  - 繰り返しの範囲の確認: 題は「繰り返しの予定を変更」か「繰り返しの予定を削除」、問いは「どの範囲に反映しますか？」です。ラジオで この予定のみ（最初の選択）/ この予定と今後の予定 / すべての予定（過去分も含む）を選び、「保存」か「削除」で確定します。「キャンセル」と × もあります。削除のときだけ、「この予定と今後の予定」の下に「取り消してもタグは戻りません。」が出ます。

  - Todo の追加（題「Todo の追加」、×）: タイトル、「追加」「キャンセル」。追加すると、そのまま Todo の詳細が開きます。

### 詳細パネル（3 つのタブ: 今日の流れ / Todo / 繰り返し）

- **今日の流れ**: Desktop では、見ている週に関係なく今日の日付です。行は時刻・題で、Todo の行にだけ完了のチェックボックスがあり、繰り返しの行には Repeat のアイコンが付きます。今の時刻の線が出ます。「スキップ済み（N件）」と、行ごとの「戻す」があります。
- **Todo**: 上から順に次のものが並びます。
  - 日の行: ‹ 日付 ›（今日なら「· 今日」）と「今日」。
  - 全幅の「絞り込み」ボタン（効いている件数を文字の後ろに出す）。押すとパネルの中に、表示するリスト（両方 / 本日分 / その他）、タグの四角いチェック、「絞り込みを解除」が開きます。
  - 「本日分の Todo」（「＋ 本日分に追加」。今日以外の日は「{{date}}（{{weekday}}）の Todo」と「＋ この日に追加」）と、「その他の Todo」（「＋ Todo」）の 2 つの一覧。
  - 行はチェックボックス・題・時刻か「終日」の丸いラベル・タグのチップです。Desktop ではホバーでアイコンが 3 つ（本日分へ移す か その他へ移す / この Todo を編集 / 削除）出て、それぞれにツールチップが付きます。Desktop では、その他の行をグリッドへドラッグできます **[保存]**。
  - 両方とも空なら「Todo はまだありません」、全部が絞り込みで隠れたら「絞り込みですべての Todo が隠れています。」です。
- **繰り返し**: 繰り返しを隠しているときは「繰り返しを表示に戻す」の案内が出ます。行は枠の無い 2 行で、1 行目が題、2 行目が頻度（「毎日」「月・水・金」）、右に「次 {{date}}」です。次の回が無ければ「実行される日がありません」です。行のクリックで吹き出しが出ます。吹き出しは、バッジ「繰り返し」・題・「毎週{{days}}曜 · 06:00–06:15」・タグと、次の回を表示 / 削除 / 詳細を編集 です。次の回が無いときは「次の回を表示」が押せず、「詳細を編集」は出ません。
- **Todo の詳細**: 予定のエディタと同じ枠で、見える見出しはありません。中身はタイトル、ステータス（未着手 / 完了）、日時（日付・終日・開始 / 終了）、「目標につなぐ」、タグ（「タグを付ける」）と「ノートを添付」、カレンダーで使う色、メモ（リッチテキスト）、「予定に変換」、フッターの「Todo を削除」「キャンセル」「保存」です。
- **読み込み中と失敗**: 読み込み中はスケルトンです（「読み込み中…」は読み上げだけ）。失敗は danger のカードで、「予定を読み込めませんでした」と「再試行」を出します。古い行が残っているときは、上に再試行の帯が出ます。

### Mobile

- 上端の帯の中央は、セグメントではなく画面名「予定」です。
- メインは月だけです。マスには題の文字が 4 行まで並び、5 件以上なら 3 行と「他 N 件」になります。選んだ日には枠が付きます。左右のスワイプで月が変わります。
- 見出しの行: 月の題、絞り込みボタン（バッジ付き）、‹ ›、今日（高さ 44px）。
- 日付をタップすると、引き出しがその日の「今日の流れ」で開きます。今日の流れのタブにだけ、見出しに「追加」の丸いボタンがあります。Mobile の今日の流れは、予定の間に「空き 1時間30分」を出し、時刻を開始と終了の 2 行で出します。
- 週ビュー・繰り返しと祝日のトグル・レンズの行・ホバーの吹き出しはありません。
- 追加は 2 段です。まず下からの短いシート「クイック追加」が開きます。中身は、種類 予定 / Todo、タイトル、日付、開始 / 終了（Todo のときは時刻が無く、終日で入る）と、「詳しく入力」「追加」です。「詳しく入力」は保存せず、入力を持ったまま全画面の「アイテムを追加」へ進みます。
- 予定のエディタと Todo の詳細は、全画面の高さのボトムシートです。予定のエディタには「タグごと複製 / タグなしで複製」が足されます。
- Todo タブの行の操作ボタンは、ホバーを待たずにいつも出ています。
- 繰り返しタブは読むだけです。削除はなく、行のタップでエディタを開きます。

## 7. つながり（connect）

### タグタブ（Desktop は 2 枚組）

- **左の列**（幅 `w-[260px]`、右に border）: 絞り込みの欄（タグ名で絞り込む）。タグの行はアイコン・名前・枠の無い「N 件」と、いつも見える ⋯（タグを編集する / タグを削除）で、選択中は左に accent の縦線が付きます。「未分類」の行（⋯ なし）。「使われていないタグ（N）」の開閉。追加の行（タグ名を入力 + 追加）**[保存]**。
- **右の列**: 見出しはアイコン・名前・件数と Pencil の切り替え（このタグを編集）、「選択」のボタンです。Pencil で編集の枠（名前、アイコンの検索付き選択、色のプリセットとカスタム、キャンセル、保存、タグを削除）が開きます **[保存]**。アイテムは種類ごと（Todo / 予定 / ノート / デイリー）にまとめます。
  - 行を押すと選ばれ、詳細パネルに関係のパネルが出ます。元の画面へ移るのは、右端の「「題」を開く」かダブルクリックです。右クリックはそのアイテムの編集を開きます。Todo の行は、丸い完了のチェックで状態を切り替えられます。
  - 「選択」を押すと、行に四角いチェックが出ます。押したあとのボタンは「選択を終える」です。
