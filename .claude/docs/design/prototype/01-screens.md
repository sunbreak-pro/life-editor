# Life Editor — 画面ごとの仕様（Claude Design に渡す資料 2/4）

> 2026-10-10 の main（`85aa99b9`）のコードと実画面から書き起こしました。文言は日本語のカタログ（`shared/src/i18n/locales/ja.json`）の写しで、言い換えずに使ってください。
> **[保存]** と付けた操作は、データの作成・編集・削除です。試作ではフォームまで開き、確定すると「試作のため保存しません」のトーストを出して閉じます。
> 寸法は既定の文字サイズ（ルート 18px）での値です。コードは rem で書かれているので、試作も rem で組みます。各画面の実測値は「実測値」の節にまとめてあります。

## 0. 全画面に共通のもの

### キーボードの近道

設定画面で割り当てを変えられます。「Mod」は Windows の Ctrl、Mac の ⌘ です。

| キー                    | 名前                   | 結果                                                             |
| ----------------------- | ---------------------- | ---------------------------------------------------------------- |
| Mod+K（入力中でも効く） | コマンドパレットを開く | パレットを開く・閉じる                                           |
| Mod+,                   | 設定を開く             | 設定へ移動                                                       |
| n（入力中は効かない）   | 新規 Todo を作成       | 予定へ移動し、右パネルの Todo タブと Todo 追加のダイアログを開く |
| Mod+1                   | Todo へ移動            | 予定へ移動し、右パネルを Todo タブで開く                         |
| Mod+2                   | デイリーへ移動         | 素材のデイリー                                                   |
| Mod+3                   | ノートへ移動           | 素材のノート                                                     |
| Mod+4                   | スケジュールへ移動     | 予定                                                             |
| Mod+5                   | つながりへ移動         | つながりのタグ                                                   |
| Mod+Z / Mod+Shift+Z     | 元に戻す / やり直し    | 試作では押せる見た目と、戻すものが無いときの無効表示だけ         |

画面の中だけで効くキーもあります。パレットは ↑ ↓ Enter Esc、セグメントコントロールは矢印キーで端から端へ回り込み、詳細パネルの幅のハンドルは ← → で 16px ずつ変わります。Esc はポップオーバー・メニュー・ダイアログ・引き出しを閉じます。

### トースト

- 種類は info / success / warning / danger の 4 つです。左端に 3px の色の帯があり、danger は AlertCircle のアイコン、ほかは色の点を出します。
- 右下に出て、4 秒で消えます。× で閉じられます。
- 文言の例: 「元に戻しました: {{label}}」「「{{title}}」を削除しました。ヘッダーの「元に戻す」で戻せます。」

### そのほか

- **オフラインの帯**: すべての上に warning の帯が出ます。WifiOff のアイコンと「オフラインです。オンライン時にご利用ください（You are offline）」です。試作パネルの状態の切り替えに「オフライン」を足すと確かめられます。
- **初めて開いた画面**: その画面を初めて開いたときだけ、下から浮き上がる入りのアニメーションが付きます（250ms、ease-out）。
- **未保存のまま離れる**: 「保存していない変更があります。破棄して閉じますか？」（キャンセル / 破棄）の確認が出ます。
- **アイコン**: ナビは Sunrise / Clock / Library / Tags / Timer / BarChart3 / Settings（18px）。サイドバーは PanelLeftClose / PanelLeftOpen / Command / LogOut、見出し行は Search / Undo2 / Redo2 / PanelRightOpen / PanelRightClose、Mobile のハンバーガーは枠付きの PanelRight、その他は MoreHorizontal です。

## 1. アプリの外枠

### Desktop

- **サイドバー**（幅 `w-60`、折りたたむと `w-16`。幅は動きを付けて変わり、折りたたみの状態は覚えておく）
  - 上端: 24px の正方形に accent 色の「L」、「Life Editor」、折りたたみボタン（サイドバーを折りたたむ / サイドバーを展開）。
  - 本流: 朝刊・予定・素材・つながり・集中・分析。タイマーが動いているときは、集中の行の下に残り時間（mm:ss）が小さく出ます。折りたたみ中は、集中のアイコンに accent の点が付きます。
  - 区切り線のあとに設定。
  - フッター: 「⌘ コマンドパレット」の行（Windows では Ctrl K のキーキャップ）、アカウントの行（表示名。未設定ならメールアドレス。ホバーでメールアドレスが出て、押すと設定のプロフィールへ）、サインアウトのアイコン。Desktop アプリでは「Claude Code を起動」の行も出ます。
  - 選択中の行は accent-subtle の地に accent の文字です。折りたたみ中はアイコンだけで、ホバーで名前のツールチップが出ます。
- **見出し行**
  - 左: 画面名、またはその画面のタブ。
  - 右（左から）: コマンドの検索欄（「検索・コマンド実行」と ⌘K のキーキャップ）、元に戻す・やり直すのアイコンボタン、詳細パネルの開閉（詳細を開く / 詳細を閉じる）。
- **見出し行のタブ**

| 画面             | タブ                                                            |
| ---------------- | --------------------------------------------------------------- |
| 朝刊             | 朝刊 / 夕刊（17 時以降は夕刊で開く）                            |
| 素材             | ノート / デイリー。それぞれに件数のバッジ                       |
| つながり         | タグ / 目標と Todo。右に「タグ {{tags}} ／ アイテム {{items}}」 |
| 分析             | 概要 / Todo / 作業 / スケジュール                               |
| 予定・集中・設定 | タブなし。画面名だけ                                            |

### Mobile

- **上端の帯**: [ハンバーガー] [セグメントコントロールか画面名] [元に戻す][やり直す] の並びです。朝刊・予定・素材・つながりはセグメントコントロール、集中・設定は画面名、分析は画面名と元に戻す・やり直すだけです。朝刊では、この帯が紙面の中の題字の上に入ります。
- **下部タブバー**: 朝刊・予定・素材・集中の 4 つ（タイマーが動いているときは集中に点）と「その他」。選択中は accent の文字です。キーボードが出ている間は隠れます。
- **その他シート**（題「その他」）: 先に「クイック操作」としてコマンドパレット（シートを閉じてからパレットを開く）・元に戻す・やり直す。区切りのあとに、つながり・分析・設定。
- **最初に開く画面**: 朝刊です。前回の画面を覚えておく設定もあります。

## 2. コマンドパレット

- 黒 30% の幕の上に、幅 `max-w-[680px]`・角丸 xl のパネルが画面の上から 12% ほどの位置に出ます。
- 上に Search のアイコン付きの入力欄（「検索、またはコマンドを入力...」）、下に高さ 480px までの一覧があります。一覧は小さな大文字の分類見出しで分かれます。
- 「移動」の分類: 朝刊・予定・素材・つながり・集中・分析・設定・ノート・デイリー。
- 文字を入れると部分一致で絞り込み、ノート / Todo / 予定 / デイリーの検索結果を分類ごとに後ろへ足します。行はアイコンと題です（FileText / CheckSquare / Calendar / CalendarDays）。
- 見つからないときは「結果が見つかりません」。
- ↑ ↓ は端で回り込み、ホバーした行が選択になり、Enter かクリックで実行して閉じます。Esc か幕のクリックで閉じます。開くたびに入力は空、選択は先頭です。
- Mobile ではその他シートから開き、キーボードが出たら見えている高さに合わせて縮みます。

## 3. 詳細パネル（Desktop）と左の引き出し（Mobile）

- **Desktop**: 見出し行の下で、メイン領域の右に押し込み式で入ります。不透明な `bg-subsidebar` に左の border。見出しは「詳細」で、閉じるボタンはありません。幅は既定 320px、240〜560px の範囲で変えられ、覚えておきます。左端の 6px の帯がハンドルで、カーソルは col-resize、ホバーで accent の 30% の色になります。
- **Mobile**: 幅 360px（画面幅の 85% まで）の左の引き出し。見出し「詳細」と ×（詳細を閉じる）。Esc・幕のタップ・×・左へのスワイプで閉じ、ハンバーガーか画面の左端から右へのスワイプで開きます。
- **中身**: 画面ごとに中身を差し込みます。何も無い画面（分析）は「表示する詳細はありません」。開閉の状態は画面を移っても保ちます。Desktop では、ノートと設定を開いたときに自動で開きます。つながりはアイテムを選んだとき、目標と Todo は目標を選んだときに開きます。

## 4. 朝刊（briefing）

紙面は中央に 1 列、最大幅 `max-w-2xl`、下に `pb-16` の余白があります。

### 朝刊タブ（上から順に）

1. **題字**: serif で字間を広げた「LIFE EDITOR 朝刊」、日付の行（例: 2026年10月10日 土曜日）、下に二重線。
2. **ゆうべの自分から**: 朱色の小さな大文字のラベルと、serif・xl の 1 行。無い日は Sunrise のアイコンと「まだありません。夕刊の『明日の自分へ』で書くと、ここに出ます。」
3. **昨日へのひとこと**（Claude が書いた日だけ）: Sparkles のアイコン付きの「Claude ・ 朝刊セクションより」の丸いバッジと、琥珀の薄塗りの段落。
4. **目標**
   - 「終わった期間の目標」の確認カード。ボタンは 持ち越す / やめる / 達成にする / あとで聞く **[保存]**。
   - 「これからの目標」を 今年 / 今月 / 今週 に分けて並べます。目標ごとに進み具合の棒（完了数/全体）か、「達成」「未接続」のチップを出します。
   - 目標ごとの「Todo をつなぐ」ボタンは、検索欄とチェックボックスの一覧のダイアログを開きます（つなぐ確定は **[保存]**）。
   - 「今週の目標を立てましょう」の入力欄 **[保存]**。
   - 「目標と Todo で開く」のリンクは、つながりの「目標と Todo」タブへ移動します。
5. **今日のスケジュール**: 見出しの右に ＋（今日のスケジュールに追加）があり、アイテム追加のパネルを開きます **[保存]**。
   - 並び順は Todo、細い線、終日の予定、時刻のある予定です。行の高さはどれも 44px です。
   - Todo の行: 幅 56px の時刻（朱色の太字）、状態のチェックボックス（未着手 / 完了。1 タップの切り替え）、題、つながった目標があれば「🎯 目標: …」の行、操作ボタン。
   - 予定の行: 時刻か「終日」、題、繰り返しなら「ルーチン」のタグ、操作ボタン。
   - 操作ボタン: 編集（予定の画面へ移動してそのアイテムを開く）と削除 **[保存]**。Mobile ではラベルを隠してアイコンだけにします。
   - 空のとき: 「今日のスケジュールはありません」。
6. **持ち越し**: 「N日目」のバッジ・チェックボックス・題・操作ボタンの行。

読み込み中は 8 行のスケルトンです。

### 夕刊タブ（上から順に）

1. 題字「LIFE EDITOR 夕刊」と「夕刊 第 N 号 · N 日連続」。
2. 今日の気分: 5 つの★（1 タップの切り替え。ホバーで何個目まで光るかを出す）。
3. 今日進んだ目標（例: 「企画書を通す 2/4 → 3/4」）。
4. 今日の出来事: 「予定 N · Todo N · 作業 N」の要約と、行ごとの「一言」の入力欄。
5. 一日の締めくくり: 振り返りのエディタ。空なら「今日のふり返りを書く」の呼びかけ。
6. 明日の予定に置く: 時刻（任意）と「明日に置く」ボタンの行 **[保存]**。
7. 残りの Todo。
8. 今後の予定（「明日」のチップ付き）。
9. 明日の自分へ: 1 行の入力欄。

### 詳細パネル

- **今日の Todo**: 朝刊タブだけ ＋ が付きます。行はチェックボックス・題・時刻のラベルです。追加できる Todo の一覧もあります。
- **きのうまでの自分**（朝刊タブだけ）: 連続日数、Todo の完了の推移のグラフ、作業と休憩の割合のグラフ。

### Mobile

上端の帯（ハンバーガー + 朝刊 | 夕刊 + 元に戻す・やり直す）が紙面の最初の行になります。ほかは Desktop と同じです。

## 5. 予定（schedule）

### Desktop

- **ツールバー**: 左に [今日] [‹ 前へ] [› 次へ] と期間の表示（例: 2026年10月）。右に、祝日のトグル（Flag。祝日を隠す / 祝日 N 件を非表示。押下中は accent）、繰り返しのトグル（Repeat。繰り返しを隠す / 繰り返し N 件を非表示）、週 / 月のセグメント、絞り込みボタン（ListFilter。タグで絞り込む。効いているときは右下に件数のバッジ）、accent の主ボタン「＋予定を追加」。領域が狭いと文字のボタンはアイコンだけに縮みます。
- **レンズの行**（保存したタググループがあるときだけ）: 「グループで絞り込む」のラベルとグループのチップ、「N 件を非表示」、「すべて表示」。
- **週ビュー**: 7 日の列と終日の行。0〜24 時で 1 時間 48px。開くと今の時刻が見える位置までスクロールします。今の時刻に線を引き、今日の列を強調します。ブロックは予定 / 繰り返し / Todo（青）で色が分かれ、タグの色の帯が付きます。空いた枠のクリック（30 分単位）はアイテム追加のパネルを開きます **[保存]**。ブロックのドラッグでの移動・伸縮・終日の行へのドロップは **[保存]** です。
- **月ビュー**: 42 マスの月。点と題のチップが並びます。マスの空いたところのクリックはその日で追加を開きます。「他 N 件」は「{{date}} の残りの予定」のポップオーバー（× 付き）を開きます。
- **アイテムを 1 回クリック**: カーソルの近くに幅 520px の 2 列の吹き出しが出ます。上に題と時刻（または終日）、操作は 名称の変更（その場の入力）/ 時間帯を変更（その場の時刻）/ 複製（タグごと複製 / タグなしで複製）/ Todo に変換 / 削除（danger）、下に「詳細を編集」。右クリックでも同じ吹き出し、ダブルクリックはエディタを直接開きます。Esc か外側のクリックで閉じます。Todo のチップは、名称の変更・Todo を削除・予定に変換だけです。どの操作も確定は **[保存]** です。
- **重ねて開くもの**
  - アイテム追加（題「アイテムを追加」）: 種類 予定 / Todo、追加方法 新規作成 / 既存から選ぶ、タイトル、日付、開始 / 終了、終日、繰り返し（なし / 毎日 / 曜日 / N日ごと）、ノートを添付。ボタンは「追加」「追加して詳細へ」。
  - 予定のエディタ: タイトル、日付、終日、開始 / 終了、繰り返し、リマインダー（通知しない / N 分前）、実績時間、メモ、タグ、色。状態の表示は「保存済み / 未保存」。削除あり。繰り返しから生まれた回は「ルーチンから生成」と「この日はスキップ」を出します。
  - 繰り返しの範囲の確認: この予定のみ / この予定と今後の予定 / すべての予定（過去分も含む）。
  - タグの絞り込みパネル: タグのチェックボックス、解除、保存したグループ（保存・適用・名前の変更・削除）。
  - Todo の追加: タイトル、追加、キャンセル。

### 詳細パネル（3 つのタブ: 今日の流れ / Todo / 繰り返し）

- **今日の流れ**: 日付の見出し。行は時刻・点・題・完了のチェックボックスです。Mobile では予定の間に「空き 1時間30分」と出て、今の位置の印があります。「スキップ済み（N件）」と行ごとの「戻す」。Desktop だけ「マイルーチン」のまとめカードと「「繰り返し」タブを開く」。
- **Todo**: 絞り込みボタン（表示するリスト 両方 / 本日分 / その他、タグのチップ、絞り込みを解除）。「本日分の Todo」（＋本日分に追加）と「その他の Todo」（＋Todo）の 2 つの一覧。行はチェックボックス・題・時刻か「終日」の丸いラベル・タグのチップで、ホバーで「本日分へ移す / その他へ移す」・開く・削除が出ます。Desktop では、その他の行をグリッドへドラッグできます **[保存]**。全部が絞り込みで隠れたら「絞り込みですべての Todo が隠れています。」
- **繰り返し**: 繰り返しを隠しているときは「繰り返しを表示に戻す」の案内。行は題・頻度（「毎日」「月・水・金」）・次の日付です。行のクリックで吹き出し（次の回を表示 / 削除 / 詳細を編集）。
- **Todo の詳細**: 種類のバッジ、題、ステータス 未着手 / 完了、日時、目標の選択、タグ、メモ。
- 読み込み中は「読み込み中…」、失敗は「予定を読み込めませんでした」と「再試行」です。

### Mobile

- メインは月だけです。日付の数字と点のコンパクトなグリッドで、左右のスワイプで月が変わります。
- 見出しの行: 月の題、絞り込みボタン（バッジ付き）、‹ ›、今日（高さ 44px）。
- 日付をタップすると、引き出しがその日の「今日の流れ」で開きます。引き出しの見出しに「＋追加」の丸いボタンがあります。
- 週ビュー・繰り返しと祝日のトグル・レンズの行・ホバーの吹き出しはありません。
- 追加は下からのシート（クイック追加）、エディタは全画面の高さのボトムシートです。
- 繰り返しタブは読むだけです。削除はなく、行のタップでエディタを開きます。

## 6. 素材（materials）

### 6a. ノート

- **メイン（ノートを選んでいるとき）**
  - 右寄せの「＋ノート」の丸いボタン **[保存]**。
  - 上に貼り付く見出し: 題の入力欄、ピンの印、⋯（その他の操作: ピン留め / ピン解除、テンプレートとして登録する、テンプレートから反映する、パスワードを設定 / 解除、ノートを削除）。
  - タグのチップと「タグを追加」の選択（検索と作成ができる）。
  - Desktop だけ、リンクのパネル（リンク、リンクを追加）と「関連を開く」。後者はダイアログで リンク / 同じタグのアイテム / 同じ日のデイリー を出します。
  - 書式のツールバー: 見出し 1、見出し 2、太字、斜体、取り消し線、区切り線を挿入。
  - 本文のエディタ（「ノートを書く…」）。`/` でスラッシュメニュー（見出し 1〜3、箇条書き、番号付きリスト、Todo リスト、テーブル、画像、ファイル）、`[[` でリンクのメニュー（ノート / デイリー / Todo のラベルと「「{{query}}」のノートを作成してリンク」）。テーブルには操作のポップオーバーがあります。
- **メイン（何も選んでいないとき）**: FileText のアイコンと「ノートを選ぶか、新しく作成してください」、「最近開いたノート」の一覧。
- **ロックしたノート**: 「このノートはロックされています」と、パスワードのダイアログを開く解除の操作。
- **詳細パネル（ノートの一覧。両方の幅）**
  - 検索欄（ノートを検索…）と並び替え（タイトル / 更新日時 / 作成日時、向きの切り替え）。
  - 「タグで絞り込む」のボタンで複数選択のパネル。
  - 既定の一覧: ピン留めが先、続いて 15 行、最後に「他のアイテム（N）」。これは Desktop ではパネルの左にはみ出す小窓、Mobile では「一覧に戻る」付きのその場の一覧を開きます。
  - タグで絞り込んだとき: タグごとのまとまり。色付きアイコンの見出しと折りたたみの山形（グループを折りたたむ / 展開）、最後に「未分類」。
  - 行: 題、ピンと鍵のアイコン、ホバーで Pencil（ノートを編集）と Trash2。
  - 右クリック（Desktop）: 行は 名前を変更 / ノートを削除、タグの見出しは タグを編集する / タグを削除。Mobile は長押しで同じメニュー。
  - ノートをタグの見出しへドラッグするとタグが移ります **[保存]**。案内は「タグにドロップして付与」。
  - 「テンプレート」の開閉と一覧。
  - 空のとき: 「ノートはまだありません」（ノートの作成ボタン付き）、「検索に一致するノートはありません」。
- **Mobile**: 一覧は引き出しに入り、ノートを選ぶと引き出しが閉じます。題の文字は小さめです。リンクのパネルと右クリックはなく、長押しを使います。

### 6b. デイリー

- **メイン（Desktop）**: 上から「今日へ」（右寄せ）、朝の記録、エディタのカード、気分と数字の帯の順に並びます。エディタのカードは 28px の日付の見出し、「保存済み / 未保存」の小さな表示、⋯（ピン留めする、エントリを削除）と本文（「今日のことを書く…」）です。本文はその日の 1 つの文章で、朝刊の夕刊の振り返りと同じものです（2026-10-10 の #2173 から）。
- **朝の記録**（本文の上。朝刊のひとことも宣言も無い日は出ません）: 枠付きのカードで、「朝刊のひとこと」と「宣言」の小さな見出しの下に文章が読み取り専用で並びます。高さは 160px（`max-h-40`）までで、超えるとカードの中でスクロールします。
- **気分と数字の帯**（本文の下。どの日にも出ます）: 枠付きのカードに、気分の★ 5 つ（15px、選んだ数まで朱で塗る。Mobile は 1 つ 44px の当たり判定）と「この日の数字」の 4 項目（予定 N / Todo 完了/全体（0 件は —）/ 作業 N時間N分 / 進んだ目標 N（無いときは —））が横に並び、狭いと折り返します。数字は読み込みが済むまで出ません。
- **無くなったもの**: 以前のスクリーンショットや資料にある「夕刊」のカード、「この日のスケジュール」、「振り返りを編集」「夕刊を書く」は #2173 で削除しました。作らないでください。
- **Mobile**: 並びは Desktop と同じです。ただし「今日へ」と ⋯ はカードの外の 1 行に並びます。日付の見出しは年の付かない「10月10日（土）」で 20.25px です（Desktop は「2026年10月10日（土）」）。気分の★は 1 つ 50×50px の当たり判定で、数字は折り返して 2 行になります。
- **「保存済み」の表示**は、本文がある日だけ見出しの右に出ます。
- **詳細パネル**: 並び替え（日付、新しい順 / 古い順）と「エントリを絞り込む…」。日付の選択ボタン（Calendar のアイコン、ラベル、ChevronDown）。「エントリ（N）」の一覧は、日付・本文の書き出し・ピンのアイコンの行で、選択中の行を強調します。Mobile で選ぶと引き出しが閉じます。

## 7. つながり（connect）

### タグタブ（Desktop は 2 枚組）

- **左の列**（幅 `w-[260px]`、右に border）: 絞り込みの欄（タグを絞り込む…）。タグの行はアイコン・名前・件数（「N 件」）で、選択中は左に accent の縦線。行ごとの ⋯（タグを編集する / タグを削除）。「未分類」の行。「使われていないタグ（N）」の開閉。追加の行（タグ名を入力 + 追加）**[保存]**。
- **右の列**: 見出しはアイコン・名前・件数と Pencil の切り替え（このタグを編集）。切り替えると編集の枠（名前、アイコンの検索付き選択、色のプリセットとカスタム、保存、タグを削除）が開きます **[保存]**。アイテムを種類ごと（Todo / 予定 / ノート / デイリー）にまとめ、行にはチェックボックスがあって選べます。
- **選択のバー**（何か選んだとき）: 「N 件を選択中」、タグを付ける、別のタグへ移す、このタグを外す（ここまで **[保存]**）、選択解除。
- **詳細パネル**: 何も選んでいないときは、種類別の内訳と「最近タグを付けたもの」。アイテムを選ぶと関係のパネル（リンク、同じタグのアイテム、同じ日のデイリー、「元の画面で開く」「このタグへ戻る」）。
- **状態**: タグ未選択は「タグを選ぶと、そこに集まったものが一覧に出ます。」、何も無いときは「タグもアイテムもまだありません。」とタグの追加ボタン、読み込み中は 6 行のスケルトン。
- **Mobile**: 1 枚ずつです。まずタグの一覧、タップでそのタグのアイテム（戻る矢印 = タグ一覧へ戻る）。チェックボックスはなく、行の ⋯ が下からのシート（関連を見る / このタグを外す）を開き、「関連を見る」は「関連: {{title}}」のシートを開きます。

### 目標と Todo タブ

- 追加の行（目標を立てる。「届きたいところを書きます」。1 つの期間に 3 つまで）**[保存]**。
- 目標の木: 年 → 月 → 週。目標ごとに「完了/全体」か「達成」、下につないだ Todo。
- そのあとに「未接続の目標」と「どの目標にもつながらない Todo」。
- 空のとき: 「目標はまだありません…」と「今週の目標を立てる」。
- 目標を選ぶと目標の詳細（目標の名前、上の目標、つないだ Todo）が Desktop は詳細パネル、Mobile はボトムシートに出ます。

## 8. 集中（work）

### Desktop（カードの縦積み、間隔 `gap-6`）

1. **タイマーのカード**: 段階のバッジ（ワーク / 休憩 / 長い休憩、止めているときは「一時停止中」）、セッションの点（「N / M セッション」）、進み具合の輪と 40px の等幅の残り時間（`25:00`）、「−5 分」「＋5 分」、主ボタン（開始 → 一時停止 → 再開）、アイコンボタンのリセット（RotateCcw）とスキップ（SkipForward）。
2. **作業名の選択**: 今後 7 日の Todo と予定のドロップダウン。未選択は「フリーセッション」、「フリーセッションに戻す」で外れます。右にフリーセッションのタグの欄（アイテムをつないでいる間は無効）。
3. **環境音**: 雨 / 風 / 海 / 鳥 / 焚き火。それぞれにオン・オフと音量のスライダー。保存ボタンは 1 つで「保存済み / 未保存」を出します。

- **詳細パネル**: タイマー設定 / 履歴 のタブ。タイマー設定は 作業・休憩・長い休憩・長い休憩まで・1 日の目標 の増減ボタン、プリセット（保存・適用・削除）、休憩を自動開始。タイマーが動いている間は薄く表示します。履歴は 今日 / 昨日 に分けた行（題かフリーセッション、「N 分」）。
- **完了のダイアログ**: 「セッション N が完了しました」と 休憩を開始 / もう 1 セッション / 閉じる。

### Mobile

- 全画面のタイマー（60px の残り時間と輪）、紐付けの行（下からのシート「作業を紐付ける」。Todo / 予定 の分類と、フリーセッションの名前の欄）、タグの行、ラベル付きの操作ボタン。
- 設定と履歴は引き出しに入ります。**環境音は Mobile にありません。**

### 試作での動き

残り時間は 1 秒ずつ減ります。開始・一時停止・リセットで段階の表示が変わり、サイドバーの集中の行と下部タブの点も動いているかどうかを映します。試作パネルに「1 秒 = 1 分」の早送りを付けると、完了のダイアログまで確かめられます。
