# 最初のプロンプト — 今の Life Editor を動く試作として再現させる

> Claude Design の新しいプロジェクトで、最初の 1 通として貼ります。下の枠（4 つのバッククォートの範囲）の中身を raw テキストのままコピーしてください。
> 同じメッセージに、`README.md` の「渡すもの」に挙げたファイルとスクリーンショットを添付します。
> 1 回のセッションで全画面は作りきれません。この 1 通では外枠と試作の仕組みと朝刊までを作らせ、残りの画面は `11-prompts-follow-up.md` の順に 1 画面ずつ足します。

```markdown
# 依頼: Life Editor の今の画面を、クリックして確かめられる試作として再現してください

## 0. この依頼の目的

Life Editor という個人用アプリの見た目（余白・文字の大きさ・配置）を、実際に動かしながら仕上げたいと考えています。そのために、まず今の画面をできるだけそのまま再現した「動く試作」を作ってください。新しいデザインの提案はまだ要りません。今の画面と同じものができてから、別のメッセージで微調整をお願いします。

添付したもの:

- `00-context.md`: アプリの説明・外枠・色・余白・文字・守ること
- `01-screens.md`: 画面ごとの構成・操作・Desktop と Mobile の違い
- `02-interactions.md`: 試作で動いてほしい操作の一覧（受け入れの確認表）
- `03-mock-data.json`: 試作に入れる見本のデータ
- `tokens.css`: 色と段階の正本（実際のアプリの CSS）
- スクリーンショット: 今の実画面。ファイル名は `<番号>-<画面>-<desktop|mobile>-<light|dark>.png` です。見た目に迷ったら、文章よりスクリーンショットを優先してください。

DesignSystem プロジェクト（部品集）も読み込まれています。部品の見た目はそちらに合わせてください。

## 1. 作るものの範囲

- 1 つの動く試作（React で構いません）として、アプリ全体を作ります。画面ごとに別のファイルへ分けても、1 つのアプリとして画面をまたいで移動できるようにしてください。
- **データの作成・編集・削除（保存）は作りません**。それ以外の操作はすべて動くようにします。具体的には、画面の移動・タブ・表示の切り替え・日付の移動・絞り込み・検索・開閉（パネル・引き出し・シート・ダイアログ・メニュー）・ホバー・選択・ドラッグでの幅変更・タイマー・テーマと文字サイズの切り替え・キーボードの近道です。一覧は `02-interactions.md` にあります。
- 作成・編集・削除のボタンは、見た目どおりに置きます。押すと入力のダイアログやフォームまでは開き、文字も打てるようにします。ただし「保存」「削除」「作成」を押したときは何も保存せず、画面下に「試作のため保存しません」というトーストを出して閉じてください。
- データは `03-mock-data.json` を読み込んだ状態から始めます。完了の印や★のような 1 タップの切り替えは、画面の上だけで切り替わって構いません（再読み込みで元に戻ってよい）。

## 2. 試作の外側に付けてほしい道具

画面の右下に、折りたためる小さな「試作パネル」を置いてください。アプリの画面とは見た目で区別できる、中立の色の浮いたパネルにします。中身は次の 4 つです。

1. **幅の切り替え**: Desktop 1440×900 / Desktop 1280×800 / Mobile 390×844 を切り替えます。Mobile では 390×844 の端末の枠の中にアプリを描きます。768px を境に外枠が切り替わることも確かめたいので、幅を自由に動かせるモードも用意してください。
2. **状態の切り替え**: 今の画面を「データあり / 空 / 読み込み中 / エラー / オフライン」のどれで表示するかを選べるようにします。オフラインは、すべての上に warning の帯を出す状態です。
3. **見た目の切り替え**: ライト / ダーク / OS に従う。言語の日本語 / 英語（英語は主要な文言だけで構いません）。文字サイズの 10 段（ルートを 12 / 13 / 14 / 16 / 18 / 19 / 20 / 22 / 23 / 25px にする。既定 18px）。
4. **微調整のつまみ**: 次の値を CSS 変数にして、スライダーか数値欄で変えられるようにします。変えた値は画面にすぐ反映します。
   - ルートの文字サイズ、文字の段（xs / sm / base / lg / xl / 2xl）
   - 余白の段（4 / 8 / 12 / 16 / 24px）と画面の左右の溝（16 / 24px）
   - サイドバーの幅（展開 / 折りたたみ）、見出し行の高さ、詳細パネルの既定幅
   - 一覧の行の高さ、カードの内側の余白、角丸の段
   - 「値を書き出す」ボタン: 既定から変えた値だけを、変数名と値の JSON にしてコピーできるようにします。この JSON を実際のコードへ戻すときに使います。

5. **そのほか**: 「サインイン画面を見る」（サインイン画面と外枠を行き来する）と、集中のタイマーの早送り（1 秒 = 1 分。完了のダイアログまで確かめるため）を置いてください。

試作パネルはアプリの一部ではないので、スクリーンショットと比べるときは閉じられるようにしてください。

## 3. 今回のメッセージで作ってほしいところ

1. アプリの外枠（Desktop のサイドバー・見出し行・詳細パネル、Mobile の下部タブバー・その他シート・上端の帯・左の引き出し）
2. コマンドパレット（Ctrl K / ⌘K で開き、文字で絞り込み、上下キーで選び、Enter で画面を移動する）
3. 試作パネル（上の 2.）
4. 朝刊（朝刊 / 夕刊の 2 タブ）を、`01-screens.md` とスクリーンショットのとおりに
5. ほかの画面は、見出しと「この画面は次のメッセージで作ります」の空の状態だけを置き、外枠からの移動ができるようにする

## 4. 再現の決まり

- 寸法は `01-screens.md` の実測値を優先してください。実測値は既定の文字サイズ（ルート 18px）での px です。コードでは rem で書かれているので、試作でも rem で組み、ルートの文字サイズを変えたときに一緒に拡縮するようにしてください。
- 色は `tokens.css` の CSS 変数をそのまま使います。値を写さず、ファイルを読み込む形にしてください。
- アイコンは lucide です。名前が書いてあるものはその名前を使います。
- 日本語の文言は `01-screens.md` に書いたものをそのまま使います。言い換えないでください。
- 今の画面にない要素を足さないでください。良くしたい点に気づいたら、画面は今のままにして、最後に「気づいた点」として箇条書きで返してください。

## 5. 返してほしいもの

- 動く試作
- 再現できなかったところ・推測で埋めたところの一覧（どの画面のどの部分か、何を根拠に埋めたか）
- 気づいた点（任意）
```
