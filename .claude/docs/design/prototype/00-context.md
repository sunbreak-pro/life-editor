# Life Editor — アプリの説明と設計の決まり（Claude Design に渡す資料 1/4）

> この資料は、Claude Design（claude.ai/design）が Life Editor の今の画面を再現するための前提です。Claude Design はリポジトリを読めないため、ここに書いた内容と添付ファイルが唯一の共有知識になります。
> 書き起こした日: 2026-10-10（main = `85aa99b9` 時点のコードから）。食い違ったときは、添付の `tokens.css` とスクリーンショットが正です。

## 1. どんなアプリか

- Life Editor は、AI と会話しながら生活を設計・記録・運用する個人用のアプリです。作者本人が主な使い手で、ほかに 10〜20 人へ配ります。各人は自分だけのワークスペースを使い、共有や権限の画面はありません。
- 中身は Web アプリ（React 19 + Tailwind CSS v4 + lucide-react のアイコン）です。同じコードが Desktop アプリ（Electron）とスマホアプリ（Capacitor）にも入ります。
- 幅 768px を境に、配置が構造ごと切り替わります。768px 以上が Desktop（左サイドバーの外枠）、768px 未満が Mobile（下部タブバーの外枠）です。
- Desktop はすべての機能を持ちます。Mobile は「読むこと」と「その場でさっと書くこと」に役割を絞っています。完了の印や気分の★のように 1 タップで終わる更新は、Mobile でもできます。
- 表示言語は日本語と英語を切り替えられます。日本語は英語より 1.2〜1.5 倍の幅をとるので、日本語の長さでレイアウトを組みます。
- Claude（AI）は MCP という外部接続を通じて、同じデータを読み書きします。朝刊の講評など、Claude が書く欄は空の日が多く、空でも画面として成り立つ必要があります。

## 3. アプリの外枠

### Desktop（768px 以上）

- **左サイドバー**: 展開時の幅は `w-60`、折りたたむと `w-16` です。rem 基準のため、既定の文字サイズ（ルート 18px）では 270px と 72px になります。地色は `bg-subsidebar` です。
  - 上端にブランド行（「L」のマークと「Life Editor」、折りたたみボタン）があります。高さは見出し行と同じで、ルート 18px で 63px（`3.5rem`）、768px 以上は `3.75rem` です。
  - 本流 6 行（朝刊・予定・素材・つながり・集中・分析）の下に区切り線があり、その下に「設定」が 1 行あります。
  - 最下部にフッターがあります。コマンドパレットを開く行（Ctrl K / ⌘K）、ユーザーのメールアドレスと「プロフィールを編集」、サインアウトです。Desktop アプリでは Claude を起動する行も出ます。
- **見出し行**: メイン領域の上に横一列で置きます。左に画面名またはタブ（下線型。選択中は accent 色の 2px 下線と text-primary の太字、非選択は text-secondary）、右端に左から「検索またはコマンドを実行」の欄（Ctrl K）、元に戻す / やり直す、詳細パネルの開閉ボタン（lucide の PanelRight）が並びます。
- **詳細パネル**: 右端に押し込み式で開きます。メイン領域の上に重ねず、メイン領域が縮みます。既定の幅は 320px で、左端のハンドルをドラッグすると 240〜560px の間で幅が変わります。地色は `bg-subsidebar` で、左に border があり、上端に「詳細」の見出しがあります。閉じるボタンは無く、見出し行の開閉ボタンで閉じます。開くときは右から滑り込み、閉じるときは即座に消えます。中身は画面ごとに変わります（設定ならカテゴリ一覧）。
- **本文の幅**: 本文の列は画面の役目で 3 種類あります。読み物の列 818px、データの列 1050px、エディタの列 1170px です。左右の溝は 16px、768px 以上で 24px です。

### Mobile（768px 未満）

- **下部タブバー**: 「朝刊 / 予定 / 素材 / 集中」の 4 つと「その他」が並びます。ホームバーの余白（safe-area）を確保します。
- **その他シート**: 「その他」を押すと下からボトムシートが開きます。中身は「分析 / つながり / 設定」のナビと、クイック操作（タグを編集など）です。
- **上端の帯**: 左端にハンバーガー（lucide の PanelRight、枠付きの正方形ボタン）、中央にセグメントコントロール（Desktop のタブの代わり）、右端に元に戻す / やり直すが並びます。
- **左の引き出し**: ハンバーガーを押すと、左から幅 360px（画面幅の 85% まで）の引き出しが開き、背後に黒 30% の幕が出ます。見出しは「詳細」で、右に × があります。Esc・幕のタップ・× ・左へのスワイプで閉じ、画面の左端から右へのスワイプでも開きます。中身は Desktop の詳細パネルと同じです。ナビ用の「その他」シートとは役割が別です。
- **タップ領域**: 押せるものは、見た目の大きさに関係なく 44×44px 以上の当たり判定を持ちます。

## 5. 形・余白・文字・動き

| 種類               | 段階                                                                                                                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文字の大きさの基準 | ルートの文字サイズを設定画面の 10 段（12 / 13 / 14 / 16 / 18 / 19 / 20 / 22 / 23 / 25px）で変える。既定は 18px。ほぼすべての寸法が rem なので、画面全体が比例して拡縮する                                            |
| 文字の段           | Tailwind の `text-*` をそのまま使う。xs だけ `0.8125rem` に上げてある（sm `0.875` / base `1` / lg `1.125` / xl `1.25rem`…）。太さは 400 / 500 / 600                                                                  |
| 余白               | 4 / 8 / 12 / 16 / 24px（`lumen-1/2/3/4/6`）。20px は意図して欠番。ただし画面の多くは Tailwind の rem の余白（`p-2` = 0.5rem など）で書かれていて、ルート 18px では 4.5px の倍数になる                                |
| アイコン           | sm `0.9rem` / md `1.125rem` / lg `1.375rem`。ナビのアイコンは 18 前後                                                                                                                                                |
| 当たり判定         | Desktop の最小は `1.75rem`、Mobile は 44px                                                                                                                                                                           |
| 角丸               | 6 / 8 / 12px と完全円                                                                                                                                                                                                |
| 影                 | sm / md / lg の 3 段。控えめに使う                                                                                                                                                                                   |
| 動き               | 150ms（hover・小さな状態変化）/ 250ms（パネル・シート・引き出しが出る）/ 400ms（画面全体）。入りは `cubic-bezier(0.22,1,0.36,1)`、出は `cubic-bezier(0.64,0,0.78,0)`。「動きを減らす」設定ではアニメーションを止める |

## 6. 守ること

1. 色は添付の `tokens.css` の値だけを使います。
2. カード・メニュー・ダイアログ・パネル・ポップオーバーの背景は完全に不透明にします。backdrop-blur は使いません。透明を許すのは、モーダルの背後の黒 30% の幕・ホバー・選択チップの薄塗り・無効状態だけです。
3. ライトとダークの両方を作ります。ダークは真っ黒ではなく `#101a2c`、ライトは真っ白ではなく `#fbf4e8` です。
4. 本文・補助・件数の文字は、地に対して 4.5:1 以上のコントラストを保ちます。
5. 状態を色だけで伝えません。ラベル・形・バンドを一緒に使います。
6. Mobile で押せるものは 44×44px 以上にします。
7. UI には 4 つの状態があります。データあり・空・読み込み中（スケルトン）・エラーです。処理中のボタンは、スピナーとラベルの差し替えと無効化を一緒に出し、ただ押せないだけの見た目と区別します。
8. 既にある部品の見た目に合わせます。Button / Card / Sheet（引き出し）/ BottomSheet / Menu / Toast / Sidebar / CommandPalette / MasterDetail（一覧と詳細の 2 枚組）/ 左端 4px の状態バンド付きカード / EmptyState / SkeletonList があります。DesignSystem プロジェクトに見本があります。
9. 日本語の入力中（変換中）の Enter で、送信や確定が走らないようにします。
