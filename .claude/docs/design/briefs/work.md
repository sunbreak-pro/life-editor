## 1. 画面要件ダイジェスト

- **目的 / 主ユースケース**: 作業（WORK）/ 休憩（BREAK）/ 長い休憩（LONG_BREAK）の 3 フェーズを回すポモドーロタイマーです。セッションは Todo か予定に紐付けて記録します。何も選ばずに始めると「フリーセッション」として、名前とタグ付きの予定（Event）に記録します（`web/src/work/WorkScreen.tsx:547-551`・`web/src/work/FreeSessionTags.tsx`）。主ユースケースは「作業名を選んで 25 分集中し、5 分休み、4 セット目の後に長く休む」です。
- **表示するデータ**:
  - タイマー: フェーズ・残り時間 MM:SS・フェーズの長さ（「/ 25:00」）・進み具合・動いているかどうか（`web/src/work/WorkScreen.tsx:330-347`）
  - セッション: セット内の位置の点と「N / M セッション」（`web/src/work/WorkScreen.tsx:242-257`）
  - 作業名の候補: Todo（削除済みを除く）と、今日から 7 日分の予定。予定の行には日付と開始時刻（終日は「終日」）を添えます（`web/src/work/WorkScreen.tsx:193-231`）。件数は 10〜30 件ほどです。
  - フリーセッションの名前とタグ（`web/src/work/WorkScreen.tsx:566-575`）
  - 設定: 作業 / 休憩 / 長い休憩の分数、長い休憩までのセッション数、1 日の目標、休憩の自動開始（`web/src/work/WorkScreen.tsx:428-472`）
  - プリセット: 名前と 4 つの設定値。件数は 0〜5 件ほどです。
  - 履歴: 今日と昨日のセッション。どちらも無いときは直近の作業日 1 日分です（#2089・`web/src/work/WorkHistoryPanel.tsx`）。
  - 環境音 5 種（雨 / 風 / 海 / 鳥 / 焚き火）のオン・オフと音量（`shared/src/components/AudioMixer.tsx:67-170`）
- **主要操作**:
  - タイマー: 開始 / 一時停止 / 再開 / リセット / スキップ。一時停止中だけ −5 分 / +5 分で残り時間を変えられます（`shared/src/components/PomodoroTimer.tsx:174-190`）。
  - 作業名: 候補から選ぶ / 外す / フリーセッションに名前を付ける / フリーセッションにタグを付ける（紐付け中はタグを使えません）。
  - 設定: 値を変えて「保存」で 1 回だけ書き込みます（#714。D-20261003-work-1 で Mobile も保存ボタンを残すと決定）。プリセットは保存 / 適用 / 削除（削除は確認ダイアログ付き = #1858）。
  - 環境音: オン・オフ、音量。音量の書き込みは「保存」ボタンを待ちます（#714）。
  - 作業セッションが終わると完了のダイアログを出します（休憩を開始 / もう 1 セッション / 閉じる）。
- **Desktop / Mobile の責務分割**: Desktop は全機能です。Mobile もタイマーは Full（`docs/requirements/mobile-scope.md` の #10）で、設定・プリセット・履歴は左の引き出しに入ります。**Mobile に無いのは環境音のミキサーだけ**です（同 #11・`web/src/work/WorkScreen.tsx:682`）。v2 の「Mobile は設定を持たない」は古い記述です。

## 2. 現状 UI インベントリ

- **host 画面**: `web/src/work/WorkScreen.tsx`。Desktop は 3 枚のカードを `gap-6` で縦に積みます（`:647`）。設定と履歴は詳細パネルの 2 タブに入ります（`:483-499`。タブの枠は Schedule と共用の `ScheduleSidebarTabs`）。Mobile は全画面のタイマー 1 枚です（`:609-640`）。
- **shared 部品（Desktop の形）**:
  - `shared/src/components/PomodoroTimer.tsx` の `card`: フェーズのバッジ（点 + 文言）、直径 200px・線 10px の輪（`:111-113`）、40px の等幅の残り時間（`:159`）、点のセッション表示、アイコンだけのリセット / スキップ（44px の丸）と「開始」の丸ピル（`:221-260`）。
  - `shared/src/components/PomodoroTodoSelector.tsx`: 「作業名」の見出し + 幅 360px までのドロップダウン（`:150-226`）。右端に `FreeSessionTags` の「タグ」と「+ タグ」が付きます（`:227`）。選択中は種類色のチップ + 14px の ×（`:174-186`）です。
  - `shared/src/components/AudioMixer.tsx`: 枠付きアイコンのトグル + 名前 + スライダー + 数値の行 × 5、下に「保存済み / 保存」（`:77-160`）。
  - `shared/src/components/PomodoroSettings.tsx` の既定の形: 見出し「ポモドーロ設定」、数値入力 5 つの 2 列グリッド（`:580-636`）、自動開始のスイッチ、「保存済み / 保存」、プリセットの行と名前入力 + 保存（`:665-700`）。
  - `shared/src/components/WorkHistoryList.tsx` の card 版: 枠付きカードの行（`:224-260`）。
  - `shared/src/components/SessionCompletionModal.tsx` の default 版: 題 + 本文の 1 文 + 3 ボタン。
- **Mobile（A 案で作り直し済み = PR #2071 / #2084 / #2089 / #2174）**: 直径 232px・線 8px の輪と 60px の数字、アイコン付きのフェーズバッジ、点と「N / M セッション」の 1 行、52px の紐付け行（中立地の丸 + 種類アイコン）、44px のタグ行、ラベル付きの操作ボタン（開始 64px / 補助 52px）、「作業を紐付ける」シート（Todo / 予定の見出し・スケルトン・0 件表示）、チェックの丸と紐付け先のチップを持つ完了ダイアログ、− 値 + のステッパーで組んだ引き出しの設定、種類アイコン付きの履歴の行（今日 / 昨日）。
- **特徴的 UI**: 1 秒ごとに 1000ms linear で縮む輪。フェーズの色は 作業 = accent / 休憩 = accent-secondary（ミント）/ 長い休憩 = 琥珀 `#f59e0b`（`shared/src/components/PomodoroTimer.tsx:77-88`）。ミントと琥珀の上の文字は常に濃い `#0a1024` です。
- **状態の現状**:
  - 空: 候補 0 件は Desktop がドロップダウンの下に一文（`PomodoroTodoSelector.tsx:232`）、Mobile がシートの中にアイコン + 見出し + 説明文です。プリセット 0 件は点線の枠に「プリセットはまだありません」、履歴 0 件はアイコン + 「まだ記録がありません」です。
  - 読み込み中: 候補は Desktop が 1 本の灰色の帯（`PomodoroTodoSelector.tsx:157`）、Mobile がスケルトンの行です。履歴はスケルトンの行です。
  - エラー: **意匠がありません**。候補と履歴の読み込みが失敗しても、画面は空の一覧と同じ見た目になります（`WorkScreen.tsx:165` は読み込み中の印だけを読み、失敗を読んでいません）。
- **今の UI の課題**（Desktop。#2037 手順 2 の採点 = 2026-10-10 の実画面から）:

1. **タイマーが主役になりきれていない。** 数字は 40px、輪は直径 200px で、幅 786px のカードの中で小さく見えます。縮めてぼかした画像では、右の詳細パネルの白い入力欄 5 つがタイマーと同じくらい目を引きます（`PomodoroTimer.tsx:111-113` / `:159`）。
2. **リセットとスキップに文字が無い。** アイコンだけの丸ボタンです（`PomodoroTimer.tsx:221-260`）。Mobile は 3 つとも下に文字を出しています。
3. **環境音のアイコンがスイッチに見えない。** アイコンを押すと音のオン・オフが切り替わりますが、オンかオフかを文字で示していません（`AudioMixer.tsx:87-100`）。オフの行は全体を 45% の透明度で薄くしていて、値「50」のコントラストは light 1.90:1 / dark 2.25:1 です。
4. **作業名の行で語が重なる。** 右端に「タグ」（アイコン付きの見出し）と「+ タグ」が並びます（`PomodoroTodoSelector.tsx:227`・`WorkTagSelector.tsx:321-351`）。作業名は 1 行のためだけにカードを 1 枚使い、タイマーのカードから 27px 離れています。
5. **設定のラベルが途中で折れる。** 「セッション間の休／憩時間」「1セットあたりのセ／ッション数」と語の途中で折り返し、「目標」の右のマスが空きます（`PomodoroSettings.tsx:580-636`）。Mobile の引き出しは短いラベル + 単位 + − / + の形で、Desktop と形が違います。
6. **環境音のカードが画面の下にはみ出す。** 1440×900 では「鳥」の行までしか見えず、焚き火の行と保存ボタンはスクロールしないと見えません。
7. **Mobile にある動きが Desktop に無い。** 数字の桁のフェードと、フェーズ切替で色がそろって移る動き（250ms）は Mobile だけです。
8. **セッションの点が薄い。** 未完了の丸のコントラストは 1.58:1 です（`SessionDots.tsx`）。
9. **読み込みに失敗したときの見た目が無い。** 候補と履歴の読み込みが失敗しても、空の一覧と同じ見た目になります（`WorkScreen.tsx:165`）。Mobile は #2054 の残りの PR（この指示書と同時に出す・未 merge）で失敗の表示を足します。Desktop はまだです。

## 3. デザイン方針（このセッションの提案）

- **残す意匠**: 円形の輪 + 中央の等幅の大きな数字、フェーズの 3 色、左にタイマー・右に詳細パネルの構成、環境音の行の「トグル + 名前 + スライダー + 数値」、設定の「保存」ボタン 1 つ。
- **変える意匠**: Mobile の A 案で決まった語彙を Desktop の幅に持ち込みます。アイコン付きのフェーズバッジ、点と「N / M セッション」の 1 行、ラベル付きの操作ボタン、中立地の丸 + 種類アイコンの作業名、ステッパーの設定、種類アイコン付きの履歴の行、チェックの丸と紐付け先のチップを持つ完了ダイアログ、の 7 つです。そのうえで、Desktop の広さを使う配置（タイマーと作業名の関係、環境音の置き場所、詳細パネルの密度）を 2〜3 案で比べます。
- **使う既存部品**: Card / Button / IconButton / Menu（ドロップダウン）/ Modal / Sheet / BottomSheet / Toast / EmptyState / SkeletonList / TagPill。
- **新規に必要な部品候補**（列挙のみ・実装しない）: 読み込みに失敗したときの行内の案内（再読み込みボタン付き）。Work のほかの部品は A 案で揃っているので、Desktop の形を足す方向で使い回します。

### 形・余白・文字

- 角丸: 6 / 8 / 12 / 16 px + 完全円（9999px）
- 余白: 4px 基調のスケール（4 / 8 / 12 / 16 / 20 / 24）。画面端の溝は 16px、広い画面で 24px
- 影: elevation 3 段（sm / md / lg）。控えめに。フラット寄りの Notion ライクな密度感
- 文字サイズは設定画面から全体を拡縮できる相対設計。極端に小さい固定 px を前提にしない

### 守るべきルール（不変式）
