### D-20260812-sched-2: 繰り返しの削除を Undo したとき、どこまで元に戻すか

- 背景: #708。繰り返しを消して Undo すると、ルーチンの行だけが戻り、一緒に消えたオカレンスと「種になっていた手動作成イベント」は消えたまま。代わりにジェネレータが当日分を**新しい id で作り直す**ため、見た目は戻ったようで中身が入れ替わっている（2026-08-11 chat-main の実測 = `si-1fe619b3` / `si-25634b94` が復活せず、`schedule-b7d3c2d2` も削除済みのまま、新 `si-9d18df3c` が生成）
- A: ルーチン + オカレンス + 種イベントを**すべて元の id で復元**する（推奨 — 「Undo = 直前の状態に戻る」に忠実。ソフトデリートの復元なので技術的に可能。とくに種イベントはこうだいさんが手で作った予定なので、消えたままなのは驚きが大きい）
- B: **種イベントだけ復元**し、オカレンスは再生成に任せる（オカレンスは派生物という整理。id は変わる）
- C: 現状のまま許容し、**削除確認の文言で予告**する（「取り消しても元の予定は戻りません」）
- 放置時: #708 は保留のまま。他の Issue（#789 / #774 / #790）を先に進める
- 期限感: いつでも（他 3 件の PR とは独立）
