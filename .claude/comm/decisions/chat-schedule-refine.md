### D-20261003-sched-1: 繰り返しの「終了時間」は何を指しますか

- 背景: #2082。終了日（その日を含む）は PR #2092 で実装済み。Issue は「終了日・終了時間」を求めていたが、終了時間の意味で作るものが変わるため実装していない。現状の `startTime` / `endTime` は 1 回分の時間帯で、シリーズの終わりではない
- A: 終了時間は作らない。終了日だけで足りる（推奨 — 毎回の時間帯は既にあり、「何日の何時に終わる」が要る場面は終了日の当日の回を 1 回だけ編集すれば表せるため。列も UI も増えない）
- B: 終了日の当日だけ、指定時刻より後に始まる回を作らない（シリーズの終わりを日時で持つ。`frequency_end_time` 列の追加 = DDL が要る）
- C: こうだいさんが別の意味で考えていた（例: 毎回の終了時刻を変えたい）。その場合は中身を一言ください
- 放置時: 終了時間は作らないまま（A と同じ状態）。#2082 は PR #2092 の merge 後も「終了時間」部分だけ未着手として残す
- 期限感: いつでも（PR #2092 の merge はこの回答を待たない）
