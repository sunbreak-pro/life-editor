### D-20260922-work-1: リロード後にタイマーの走行状態を復元するか

- 背景: #1857 / PR #1909。リロードで残る `timer_sessions` の行は、次の起動時に閉じるようにした。タイマー自体は今までどおり停止状態に戻り、選択中の作業名とセッションドットも消える。復元するなら、フェーズ・開始時刻・経過・作業名を localStorage に持ち、起動時に続きから走らせる
- A: 復元しない（推奨 — 記録は欠けなくなったので実害は「もう一度 Start を押す」だけ。復元は「離席中に完了時刻を過ぎていたらどう扱うか」「別タブで同時に開いたらどちらが走るか」の分岐を連れてくる）
- B: 復元する（リロードしても同じ残り時間から走り続ける。上の 2 つの分岐の仕様を決めてから実装する）
- 放置時: A（復元しない）。#1857 は PR #1909 の範囲で閉じる
- 期限感: いつでも

### D-20260922-work-2: サイドバーを畳んだとき / スマホ幅で、タイマー走行中をどう見せるか

- 背景: #1858 の 3 点目 / PR #1916。サイドバーを開いた状態では Work 行の下に残り時間がすでに出る（`shared/src/components/NavTimerStatus.tsx`・#550）。出ないのは、畳んだサイドバー（`NavItem` が `collapsed` のとき sublabel を隠す）と、スマホ幅の下部タブバー（sublabel を受け取らない）の 2 か所
- A: Work のアイコンに小さな点を付ける（推奨 — 両方の場所で同じ見せ方になり、幅を取らない。残り時間は Work を開けば見える）
- B: アイコンの下に残り時間の数字を出す（情報は多いが、畳んだサイドバーとタブバーの行の高さが変わる）
- C: 何も足さない（開いたサイドバーの表示で足りるとする）
- 放置時: C（現状維持）。#1858 は 3 点目だけを残して open のまま
- 期限感: いつでも
