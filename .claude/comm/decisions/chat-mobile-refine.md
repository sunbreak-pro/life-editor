### D-20260730-mobile-3: パスワード付きノートのモバイル詳細シートは「全部ロック」か「本文だけロック」か

- 背景: #471 でモバイルのノートシートがフル編集になった。Desktop は**本文だけ**をぼかして鍵アイコンを重ね、タイトル・タグ・ピン・削除は解錠なしで触れる（`NotesView.tsx` の `detailContentEditor`）。モバイルは解錠 CTA をパネルごと差し替える実装にした（= 解錠しないと何も編集できない）
- A: **全部ロック**（実装済み・推奨 — 端末を人に見せる場面が多いのがモバイル。ロック中のノートの改名・タグ替えができる Desktop の方が穴として広いので、そちらに合わせて広げたくない）
- B: Desktop と同じ「本文だけロック」に揃える（面ごとの差をゼロにする。ただし穴の広い側に寄せる）
- 放置時: A のまま
- 期限感: いつでも（B に寄せるなら Desktop 側を A に寄せる案もあるので、その時にまとめて判断）

### D-20260730-mobile-2: 背の高いモバイルシートに明示的な「閉じる」ボタンを付けるか

- 背景: #470 の詳細シートは `min-h-[70vh]`〜`max-h-[92vh]`。旧ステータスシートは「選ぶ＝閉じる」で必ず出口があったが、詳細シートは自動で閉じない。出口は背景タップ（最大時は残り 8vh）と Escape（物理キーボードのみ）で、grab handle は `aria-hidden` の飾り（ドラッグ未配線）。QA レビューの MINOR 指摘
- A: **現状維持**（推奨 — ノートの読み取りシート `NotesView.tsx` と同形。既存の作法を崩さない。背景タップは 8vh でも届く）
- B: `BottomSheet` に閉じるボタンを追加（全シート共通で出口が増える。ただし共有部品の API とヘッダー体裁を全利用箇所ぶん変える）
- 放置時: A のまま
- 期限感: いつでも（実機で背景タップの取りづらさを感じたら B へ）

### D-20260730-mobile-1: モバイル詳細シートのステータス操作は 3 択タッチ行か、Desktop と同じ巡回ボタンか

- 背景: #470（PR は本ブランチ）。`shared/src/components/TaskStatusChoices.tsx` を新設し、`TaskDetailPanel` の `statusControl` スロットに差し込んだ。Desktop は従来どおり 1 ボタン巡回（未着手 → 進行中 → 完了）
- A: **3 択のタッチ行**（実装済み・推奨 — 1 タップで確定し、選択肢が全部見える。巡回だと「完了」まで最大 2 タップかかり、次に何になるか画面から読めない）
- B: Desktop と同じ巡回ボタンに揃える（面ごとの差をゼロにする。シートの縦を 1 行分節約できる）
- 放置時: A のまま（実装済み・merge 後もそのまま動く）。B に寄せたい場合は `KanbanView` の `statusControl` を渡さないだけで戻せる
- 期限感: いつでも（後から戻すコストは小さい）
