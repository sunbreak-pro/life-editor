# /loop-prune — 増えた常時ロードを畳む

`/loop-postmortem` が知見を**足す**側、本ループが**戻す**側。対で回して初めて釣り合う。片方だけ回すと、足し続けるか削り続けるかのどちらかに倒れる。

## 目標

毎セッション必ず積まれる記述（常時ロード分）を棚卸しし、**移送先があるものだけを移す**。移送先が無いものは「残す」で終える。残す判断も成果に数える。

## 完了条件（機械検証可能）

- 開始時と終了時に `context-cost-measure.mjs` を回し、両方の数値が計測結果ファイルに追記されている
- 畳んだ記述それぞれに「移送先ファイル + そこに存在することを示した grep 結果」がついている（消失ゼロ）
- 残した記述それぞれに、残す理由が 1 行ついている
- 移送先がすべて**既存ファイルの既存の節の中**にある（新規ファイル・新規章を作っていない）
- `LC_ALL=C bash scripts/docs-lint.sh` が緑

## 予算

- 反復上限: **5 件**（1 反復 = 1 記述の判定）。多い月でも 5 件で切り、残りは次回に回す
- 時間上限: **30 分**。開始直後に `START_TS=$(date +%s)` を取る
- **1 件につき畳むのは 1 か所**。ついでに隣も直したくなったら、それは別の 1 件として次回に回す

## 停止条件（人間に返す）

- **移送先を新設すべきか判断が割れた**（既存のどこにも収まらず、新しい置き場を作る話になった）
- **実体の無い禁止を消そうとしている** — 機械（hooks / permissions / lint）に実体を作るのが先で、それは棚卸しではなく実装の話
- **移行（Electron + Capacitor + Web + Supabase）が未完了なのに移送に手が伸びた** — 移送先自体が動く。検出と記録で止めて次回に回す
- **グローバル資産（`~/.claude/`）に手が伸びた** — 別リポジトリで PR も別。Scope に入れるかは未裁定（D-20260806-main-2）
- **削った量が成果に見えてきた** — 目的化のサイン。削りすぎは探索コストを増やして逆に高くつく
- 同じ記述が 3 回連続で「残す」判定になった（棚卸しの問題ではなく、置き場の設計を見直す話）

## 使ってよい道具

- `.claude/scripts/context-cost-measure.mjs` — 固定費の内訳を測る（`--sections` で上位項目を節ごとに分解）
- `.claude/docs/vision/claude-md-layering.md` — 航法 / 目的の振り分け表と移送先の一覧。**判断の正本**
- `.claude/docs/reports/2026-08-06-context-fixed-cost-baseline.md` — ベースライン。再測定はここに追記する
- `docs-workflow` スキル — 移送先（Issue / `docs/known-issues/` / `rules/` / skill）の境界の正本
- `task-tracker` スキル — per-chat の記録
- `scripts/docs-lint.sh`（`LC_ALL=C` 付き）

## 環境の事実（推論では埋まらないので明記する）

- **`ondemand` を削っても固定費は 1 tok も減らない**。スキル本体は起動時にしか読まれない。最大の塊（`ondemand` 合計は `always + listing` の 4 倍以上）だが、ここを削るのは棚卸しではなく別の話
- **死んだスキルのポインタ 8 本は 0 tok**（解決できないのでロードされない）。消しても固定費は減らない。「削減」に数えない
- **`rules/` の always / scoped は frontmatter の `paths:` の有無で機械的に決まる**。`paths:` を足せば常時ロードから外れる — 削らずに費用を下げる手段がこれ
- **MCP サーバーを切っても固定費はほとんど減らない**。deferred tools（ツール定義を必要時に取り寄せる遅延ロード）により、名前だけが載ってスキーマは `ToolSearch` 時にロードされる
- **固定費の約 66% は `~/.claude/`（別リポジトリ `claude-dotfiles`）にある**。プロジェクト側だけを削っても、効く上限は 3 分の 1
- **計測の係数を変えると過去の測定と比較できない**。変えるなら計測結果ファイルに併記する
- **`output style` はメイン会話にしか届かない。`rules/` と global CLAUDE.md はサブエージェントにも届く**（2026-08-07 実測）。「重複しているから落とす」の前に**誰に届いているか**を確かめる — 届き先が違えば、それは重複ではなく別々の読者向けの原本
- **置いたばかりのスキルは、merge してセッションを開き直すまで `Skill` ツールから起動できない**（セッション開始時のスキル一覧に載らないため）。1 周目は定義に沿って手で回すことになる
- **このカタログ自身も棚卸しの対象**。`loop-*` を 1 本増やす前に、1 本畳めないか必ず確認する（本数の正本は `.claude/skills/` のディレクトリ。旧「4 本上限」は本ループが来るまでの暫定だった）

---

- **残す判断を恐れない**。判定式は「消したら Claude が間違うか」+「毎回必要か」で、削減量ではない
- 実測した件数・所要時間は、区切りで `2026-08-04-context-cost-reduction-harness.md` の Worklog に 1 行足す
