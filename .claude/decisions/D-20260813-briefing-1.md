# D-20260813-briefing-1: 「今週」カードに残る 2 つの週の窓（グラフ・週次集計）も暦週に寄せるか

## 背景

（キュー原文 = `comm/decisions/chat-briefing-refine.md`。昇格とキューからの除去は chat-main が代行した）

#780（[`D-20260811-refactor-1`](./D-20260811-refactor-1.md) = A）で「今週」ラベルの**数字**は暦週に統一した。実装中に、同じ画面の**数字以外**が別の窓のままだと判明した 2 箇所 —

1. モバイル「今週」カード内の週バー = `aggregateByDay(sessions, 7)` の**直近 7 日**（`shared/src/components/Analytics/MobileAnalyticsView.tsx:121`）
2. Work タブの週次集計 = 私有 `startOfWeek()` が**月曜固定**（`shared/src/utils/analyticsAggregation.ts:162`・消費は同ファイル `:220` / `:233`）

#780 の裁定文は「週バーのグラフが月〜日で描かれている」を前提にしていたが、実測ではバーは直近 7 日で、前提が事実と食い違っていた。表示が変わるため P-005 / P-008 に従い実装せずキューへ積んだ。

## 選択肢と裁定

- A: **両方とも暦週（週開始曜日の設定に追従）に寄せる**（**採用** — ユーザー回答 2026-08-13「実際に寄せたい」）
  - 理由: #780 の「グラフと数字が同じ窓を見る」という理由をそのまま満たす。片方だけ直すと、同じカードの中で数字とバーが別の週を指したまま残る
  - 代償: 週の途中では未来の日が空バーになり、バーの本数の意味が「直近 7 日」から「今週」に変わる。Work タブの週次集計は週開始曜日の設定を日曜にしている場合に境界が動く（挙動変更ゼロの例外として PR 本文に明記する）
- B: バーは直近 7 日のまま据え置き、Work タブの月曜固定だけ設定追従にする（却下 — 見た目の変化は最小だが、「今週」カードの中で数字とバーの窓が食い違ったまま残る）
- 放置時 = 現状維持（#780 で数字だけ統一された状態）。ユーザー回答により選外

## 波及

- 実装 Issue = **#860**（`[analytics]`・`section:analytics` = briefing-refine レーン）
- 週の開始曜日は既存の `useWeekStartPref` に従い、月曜固定にしない（#780 と同じ規律）
- `WorkTimeChart.tsx:56` の `aggregateByDay(sessions, 14)` は「今週」カードではない別の窓なので対象外
