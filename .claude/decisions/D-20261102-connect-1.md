# D-20261102-connect-1: 目標と Todo のタブの広い画面で、上の目標を「なし」に戻す手段を足すか

## 背景

#2410 / PR #2452。試作どおりリンクだけにしたので、ドラッグでは別の目標へ移すことしかできない。朝刊のパネルとスマホには select が残る

## 選択肢と裁定

- A: リンクの横に「外す」ボタンを足す（**採用** — ユーザー回答 2026-11-02 / タブの中で完結し、試作の見た目をほぼ崩さないため）
- B: 試作どおりリンクだけにする（戻すときは朝刊のパネルを使う）（却下 — 広い画面のタブから「なし」に戻す手段がなくなり、朝刊のパネルへ回り道が要るため）

## 却下案が復活する条件

ボタンが試作の見た目を崩すと実機で分かったとき、またはドラッグで「なし」に戻す操作を足すとき。

## 波及

PR #2452 にリンクの横の「外す」ボタンを足す。
