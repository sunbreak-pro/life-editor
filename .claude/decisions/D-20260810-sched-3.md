# D-20260810-sched-3: #625 Event → Todo で落ちるフィールド（時刻・終日・繰り返し）の扱い

## 背景

#625。Todo には開始 / 終了時刻・終日フラグ・繰り返し設定に対応する行が無いので、変換時にこの情報は必ずどこかへ行く。

## 選択肢と裁定

- A: **破棄する。ただし変換の確認ダイアログで「時刻・繰り返し設定は失われます」と明示**。（**採用** — ユーザー回答 2026-08-10。実装が単純でメモを汚さない。変換は「性質の整理」の操作で、時刻が要るならまた Event に戻すより付け直す方が自然。往復非対称は認識済み）
- B: メモ欄へ機械追記で退避（例: 「変換前: 08/10 10:00-11:00」）。（却下 — メモに機械追記が積もる。繰り返し設定の文字列化は表現が煩雑）
