# D-20260829-web-2: プライバシーポリシーに Supabase のリージョンを明記するか

## 背景

（キュー原文 — 回答に伴い本 PR でキューから削除）

#1198（PR #1222）。Issue 本文は「Supabase（US/EU リージョン明記）」を求めているが、リポジトリからは判別できなかったため、初版は「日本国外のデータセンター」と書いた（US でも EU でも真になる書き方）。

## 選択肢と裁定

- A: 実際のリージョン名を書く（**採用** — ユーザー回答 2026-08-30。実測で db ホストが AWS `ap-northeast-1`（東京）の IPv6 帯に解決され、3 系統の独立ソースが一致。**従来の「いずれも日本国外」は Supabase について事実誤りだったため訂正込み**で PR #1296 として実装・merge 済み。merge 前にダッシュボード Project Settings → General の Region 表示との一致確認を条件とした）
- B: 「日本国外」のままにする（却下 — 越境移転の告知としては足りる書き方だったが、Supabase については事実と異なることが実測で判明した）

## 波及

- `web/src/legal/legalContent.ts` の保管場所節（PR #1296）
- Google Fonts 等の他サービスに関する「国外」記述は従来どおり（訂正対象は Supabase の記述のみ）
