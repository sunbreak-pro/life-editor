# D-20260705-main-1: アプリ内 Terminal を存続させるか機能ごと退役するか

> 出自: キュー原文なし — CLAUDE.md §2 / §5 / §8 のインライン注記と移行 SSOT §5-B の退役宣言から再構成（2026-08-09 バックフィル）。

## 背景

アプリ内ターミナル（portable-pty）は Claude Code を起動して MCP に繋ぐための導線として Tier 1 に置かれていた。Electron + Web への移行で pty をブラウザ側に持てず、導線としての役割も「ユーザーが自分のターミナルから `claude` を叩く」で代替できる。

## 選択肢と裁定

- **採用**: 機能ごと退役する（ユーザー決定 2026-07-05）。**MCP Server 自体は存続**し、常設の起動導線は生成デザイン確定後に再設計する
- 却下: Electron 側だけ pty を残す（Web / Mobile との機能差が固定化し、$0 での完成を遠ざける）

## 波及

- `SectionId` / nav / i18n から `terminal` を除去（#146）
- CLAUDE.md §2 / §5 / §8 の注記・`tier-1-core.md` は本文を履歴として保持
- 移行 SSOT §5-B のブリッジ項目と Phase 5 完了判定の該当 1 項は、導線再設計後に再定義する
