# D-20260704-main-1: Phase 5-A で汎用 Database と File Explorer をどうするか

> 出自: キュー原文なし — CLAUDE.md §8 のインライン注記と移行 SSOT §Phase 5-A のチェック行から再構成（2026-08-09 バックフィル）。日付は CLAUDE.md へ注記が入った commit（#115）に拠る。

## 背景

移行の Phase 5-A（周辺機能整理）で、Tauri 時代から残る 2 機能の扱いを決めた。File Explorer はローカルファイルを前提にしており Web では用途が無い（materials は Supabase Storage へ移る）。汎用 Database は実装済みだが MCP 未対応で、移行の完成に必須ではない。

## 選択肢と裁定

- **採用**: 汎用 Database は**一旦凍結**、File Explorer は**退役**。どちらも `docs/requirements/` の本体は履歴として保持する
- 却下: 両方とも移行と同時に作り直す（移行の完成が遠のく。凍結なら後から再開でき、退役は requirements を残せば復活の材料が消えない）
