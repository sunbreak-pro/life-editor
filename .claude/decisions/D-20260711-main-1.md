# D-20260711-main-1: Routine を UI 上の独立アイテム型にするか実装詳細に隠すか

> 出自: キュー原文なし — CLAUDE.md §4 のインライン注記（「2026-07-11 #185 決定」）から再構成（2026-08-09 バックフィル）。

## 背景

Routine は Event を生成するテンプレートで、DB 上は独立した role を持つ。これを UI にも「ルーチン」という 3 つ目のアイテム型として出すと、ユーザーは Task / Event / Routine の使い分けを覚える必要が出る。

## 選択肢と裁定

- **採用**: UI 上は「単一アイテム型（Event）+ 繰り返し設定」として提示し、Routine は実装詳細に留める。Routine 専用の Tag / Link UI も持たない（必要なら生成された Event 側に付与する）
- 却下: Routine を独立したセクション / アイテム型として出す（概念が 1 つ増える割に、ユーザーがやりたいのは「繰り返す予定を作る」だけ）
