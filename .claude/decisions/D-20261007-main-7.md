# D-20261007-main-7: レート制限を窓口の最初の範囲に入れるか、対象外にするか

## 背景（キュー原文）

- 背景: 計画書 R10。今はレート制限がなく、Workers の無料枠は全利用者で共有。Worker は KV と Durable Objects を使わないので、作り方が限られる。
- A: 対象外にして Non-goals に書く。鍵が漏れたら 1 本だけ取り消す（推奨 — 使うのは 1 人で、取り消し（R3）が先にあれば足りる。復活条件 = 無料枠を使い切る事故が起きたとき）
- B: 範囲に入れる（無料枠を守れる。代わりに KV 等を使わない作り方を探す手間が要る）
- 放置時: 対象外として進める（Non-goals に書く）
- 期限感: 窓口の着手前まで

## 裁定

A（**採用** — ユーザー回答 2026-10-07、チャットの選択式の質問）: レート制限は対象外にして Non-goals に書く。鍵が漏れたら 1 本だけ取り消す。
