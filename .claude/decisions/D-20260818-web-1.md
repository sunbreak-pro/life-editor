# D-20260818-web-1: iOS ホーム画面アプリのステータスバーは `default` と `black` のどちらにするか

## 背景

（キュー原文 = `comm/decisions/chat-web-public.md`）

- #1009 / PR #1061 は `default` で出済み（`web/index.html` の 1 語）。`black-translucent` は文字色が**白固定**で朝刊（クリーム `#fbf4e8`）だと読めないことが仕様上確定し、テーマ連動は不可能（この meta は起動時に一度しか読まれず、`theme-color` / manifest の `theme_color` も iOS のステータスバーには効かない）。残るのは固定 3 値からの選択のみ
- A: `default`（推奨 — 朝刊はほぼ地続き / 夕刊は上に明るい帯が 1 本）
- B: `black`（夕刊はほぼ地続き / 朝刊は上に黒い帯が 1 本）
- 放置時: PR #1061 を merge せず保留（朝刊の時間帯だけ時計・電池が読めない状態が続く）

## 選択肢と裁定

- A: **`default`**（**採用** — ユーザー回答 2026-08-19）。理由: 朝刊テーマでの可読性が現状の実害（白文字が読めない）で、`default` はその朝刊でほぼ地続きに見える。夕刊で入る明るい帯 1 本は許容
- B: `black`（却下 — 夕刊寄りの見た目は良くなるが、実害が出ていたのは朝刊側）

## 却下案が復活する条件

- 実機で夕刊の明るい帯が想定より目立つと分かったとき（`web/index.html` の 1 語なので切り替えは安い）

## 波及

- **PR #1061 の merge はユーザー手番**（P-001）。merge されるまで現状の `black-translucent` が残る
