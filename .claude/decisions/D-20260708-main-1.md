# D-20260708-main-1: `life-editor-ipc-validator` エージェントを retire するか作り替えるか

> 出自: キュー原文なし — CLAUDE.md §7.0 のインライン注記（「`-ipc-validator` は Tauri IPC 前提のため 2026-07-08 retire」）から再構成（2026-08-09 バックフィル）。

## 背景

整合監査エージェント 3 本のうち `-ipc-validator` は Tauri の IPC 境界（`invoke()` の呼び出し規約）を検査する前提で作られていた。Tauri 退役でその境界自体が消え、検査対象がゼロになった。

## 選択肢と裁定

- **採用**: retire する。残る 2 本（`life-editor-migration-validator` / `life-editor-sync-auditor`）は継続
- 却下: DataService 境界の検査へ作り替える（境界の検査は `rules/frontend.md` + lint が既に担っており、二重実装になる）
