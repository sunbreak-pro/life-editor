# D-20261003-sched-1: 繰り返しの「終了時間」は何を指すか

## 背景

（キュー原文 — 回答に伴いキューから削除）

- 背景: #2082。終了日（その日を含む）は PR #2092 で実装済み。Issue は「終了日・終了時間」を求めていたが、終了時間の意味で作るものが変わるため実装しなかった。現状の `startTime` / `endTime` は 1 回分の時間帯で、シリーズの終わりではない。
- 放置時: 終了時間は作らないまま。
- 期限感: いつでも（PR #2092 の merge はこの回答を待たない）

## 選択肢と裁定

- A: 終了時間は作らない。終了日だけで足りる（**採用** — ユーザー回答 2026-10-03 / 毎回の時間帯は既にあり、「何日の何時に終わる」は終了日当日の回を 1 回だけ編集すれば表せる。列も UI も増えない）
- B: 終了日の当日だけ、指定時刻より後に始まる回を作らない（却下 — `frequency_end_time` 列の追加 = DDL が要る）
- C: 別の意味で考えていた（該当せず）

## 却下案が復活する条件

終了日当日の回の手編集が頻発し、シリーズの終わりを日時で持つ要望が繰り返し出たとき。

## 波及

コード変更なし。#2082 は PR #2092 の終了日で足りる扱い。
