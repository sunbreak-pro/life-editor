# D-20260810-main-2: プロジェクト固有スキル / エージェントの実体をどこに置くか

## 背景

`.claude/skills/` の 8 本と `.claude/agents/` の 2 本が、リポジトリ外の共有ライブラリ（`~/dev/Claude/skill-lib` / `agents-lib`）を指す **Mac 絶対パスの symlink**（git mode `120000`）としてコミットされていた（known-issues 031）。共有ライブラリ側は git リポジトリですらなく、Windows 実機へ配る経路が存在しない。Windows セッションではこれらが一覧に載らず、名指しで委譲する指示が**エラーも出さずに空振り**していた。

hooks は同じ構造を fallback chain（`$HOME/dev/Claude/hooks-lib` → 無ければ `.claude/scripts/hooks-lib/`）で解決済みだが、**スキル / エージェントには同じ手が使えない**。Claude Code はスキルをディレクトリ一覧で発見するため、間に振り分けスクリプトを挟む余地が無い。

## 選択肢と裁定

- A: **repo 内 vendor 化・共有ライブラリ側は削除**（**採用** — ユーザー回答 2026-08-10）。10 本を実ファイルとしてリポジトリに取り込み、life-editor repo を唯一の正本にする。`skill-lib` / `agents-lib` の `projects/life-editor/` は削除して二重管理を断つ（他プロジェクト分は無傷で残す — 下記「削除の前提条件」参照）
- B: repo に実体化しつつ共有ライブラリ側も残す（却下 — どちらを直したか分からなくなる二重管理。改名 sweep で片側だけ更新される事故が実際に起きている = ink→lumen 3 世代併存）
- C: `skill-lib` 自体を git 化して submodule 参照（却下 — 複数プロジェクトで共有し続けられる利点はあるが、submodule は Windows での運用コストが高く、N=1 のプロジェクトに対して仕組みが重い）

## 波及

- `.claude/skills/`（8 本）・`.claude/agents/`（2 本）を mode `120000` → `100644` に置換
- `Skill.md` → `SKILL.md` 正規化 5 本（case-sensitive な FS で読めない潜在バグの解消）
- CLAUDE.md §4 / §7.0 の「Mac のみ実体」注記を削除し、§7.0 に「repo 外を指す symlink を作らない」不変式を追加
- `rules/docs-consistency.md` §2 の sweep 対象から repo 外 grep を削除
- `skills/loop-implement` / `loop-triage` / `loop-postmortem` の環境注記を更新
- known-issues 031 を Fixed 化
- **vendor 化で新たに生じたリスクへの応急**: 5 本（`db-migration` / `add-ipc-channel` / `add-component` / `add-feature` / `test-writing`）は現行アーキ未追随（削除済みの `electron/` `frontend/` を指し、`db-migration` は SQLite `PRAGMA user_version` 前提で実体の Supabase migration と食い違う）。symlink 時代は「読めない = 空振り」で無害だったが、実ファイル化で「読めて、間違っている」に変わる。本 PR では冒頭 STALE バナーで発火を止めるに留め、**書き直すか retire するかは別判断**（キュー送り）

## 削除の前提条件（共有ライブラリを消す前に全部満たすこと）

1. 本 PR が merge 済み
2. **全 worktree が `origin/main` を取り込み済み**（merge だけでは各 worktree の作業ツリーは変わらない）。確認 = 各 worktree で `ls -la .claude/skills | grep -c '^l'` が 0
3. `agents-lib/projects/life-editor/` に残る **`subagent-coordinator.md` の処遇を決めてある**（vendor するか retire するか。2026-07-11 まで保守されており、`claude-dotfiles/claude/agents/multi-session-coordinator.md` から参照されている。`life-editor-ipc-validator.md` は retire 済み = D-20260708-main-1 なので破棄可）
4. 削除対象は **`projects/life-editor/` だけ**。`skill-lib` / `agents-lib` 本体はまだ消せない — 未移行のリポジトリが残っている（実測 2026-08-10: `novel` = skills 13 / agents 8、`terminal-division` = skills 9、`original-card-battle` = agents 3 + skills 1、`battle-bakeoff` = agents 3。`projects/_shared/feature-files` は 2 repo が共有）
