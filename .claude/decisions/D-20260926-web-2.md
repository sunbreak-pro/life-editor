# D-20260926-web-2: Dashboard の認証メールテンプレートに日本語版と英語版のどちらを入れるか

## 背景

（キュー原文 — 回答に伴い本 PR でキューから削除。2026-09-28 に chat-main が回答を転記・昇格した）

- 背景: #1986（PR #1999）。Supabase はテンプレートを種類ごとに 1 本しか持てず、ユーザーの言語で出し分けない。アプリも `signUp` でユーザーの言語を記録していない。控え = `supabase/templates/auth/{ja,en}/`
- A: 日本語版（推奨 — 作者と当面の配布先の主な言語に合わせる）
- B: 英語版
- C: `signUp` の `options.data` に言語を載せ、テンプレート内の `{{ if eq .Data.<key> "ja" }}` で出し分ける（コード変更が要るので別 Issue）
- 放置時: Supabase 既定の英語テンプレートのまま
- 期限感: 送信サービスの設定と同じタイミング

## 選択肢と裁定

- A: 日本語版（**採用** — ユーザー回答 2026-09-28「日本語でおねがい」。作者と当面の配布先の主な言語に合わせる）
- B: 英語版（却下 — 当面の配布先の主な言語と合わない）
- C: `signUp` に言語を載せてテンプレート内で出し分ける（却下 — コード変更が要り、配布先が日本語中心の今は必要がない）

## 却下案が復活する条件

- 英語を使う配布ユーザーが加わった場合は、C（言語での出し分け）を別 Issue で再検討する

## 波及

- Supabase Dashboard の認証メールテンプレートに `supabase/templates/auth/ja/` の内容を入れる。入れるのはユーザーの作業で、送信サービスの設定（D-20260926-web-1）と同じタイミングで行う
