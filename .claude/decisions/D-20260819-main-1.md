# D-20260819-main-1: 残る `vh` 7 箇所を `svh` へ sweep するか

## 背景

出典 = `comm/outbox/chat-shared-fix.md` 2026-08-18 §4（起票判断の依頼）→ Issue #1100 として起票。

#999 の調査で `vh` を使う箇所が 7 つ残っていた（`WeekTimeGrid.tsx:437` / `TagEditModal.tsx:296` / `ShortcutEditModal.tsx:219` / `PomodoroTodoSheet.tsx:58` / `GraphSettingsSheet.tsx:40` / `NoteTemplatePanel.tsx:119` / `CommandPalette.tsx:247` ほか）。ただしどれも中央寄せのモーダル / ドロップダウンで、#633 の「上端がビューポートを越えて内部スクロールもできない」罠とは形が違う。`WeekTimeGrid` の値は `shared/tests/weekTimeGridVariants.test.tsx:141-155` が 3 箇所で pin している。

- A: まとめて `svh` へ sweep する（1 PR・テスト追随込み）
- B: 放置する（`wontfix` で close）

## 選択肢と裁定

- B: **放置**（**採用** — ユーザー回答 2026-08-19）。理由: `svh` が要るのは「ビューポートの端に貼り付く面」（ボトムシート・全画面シート）であって、中央寄せの箱ではない。アドレスバーの伸縮で高さが少し変わるだけで、隠れる辺が無い
- A: sweep（却下 — 実害の無い置換のためにテスト 3 箇所の pin を書き換えることになる）

## 却下案が復活する条件

- モーダルのいずれかが「上端 / 下端に貼り付く」レイアウトへ変わったとき（そのときは個別に `svh` へ寄せる）
