# 画面から呼ばれていない 12 件を消すか

## 背景

> キューを経ていません。2026-11-16 に main のチャットが AskUserQuestion で聞いた問いを、そのまま写しました。

- **何が起きているか。** 機能の棚卸しで、画面から呼ばれていない残りが 12 件見つかりました。Playlist のデータ処理、何もしない自動更新の骨組み、呼ばれていない Desktop の連絡口 4 本、中身のない設定カテゴリ 4 つ、Tips のモーダル、古い「宣言」を読む処理、目標ノートからの一回きりの移し替え、編集ロックなど入口のない処理、Todo の優先度などの項目、読み手のない表を購読する処理、呼び出し元のない文言ファイル、AI のカスタマイズです。AI のカスタマイズだけは画面と MCP の道具 8 つがあり、ルール・記憶・スキルが 3 つとも空でした。
- **なぜ決める必要があるか。** 決まらないと、掃除の Issue を立てられません。
- **推奨と根拠。** AI のカスタマイズ以外の 11 件を消すほうを推奨しました。AI のカスタマイズは中身が空でも機能として動くので、消すかは別に聞く必要があるためです。

## 選択肢と裁定

- AI のカスタマイズ以外の 11 件を消す（**採用** — ユーザー回答 2026-11-16）
- 12 件とも消す（却下）。AI のカスタマイズ（画面約 1,300 行と MCP の道具 8 つ）も消す案でした。
- 期日のあとに回す（却下）。害が無いのでそのまま残す案でした。

## 波及

- 実装は 2 つの Issue です。共有のコードと Web の 9 件が #2757、Desktop の 2 件が #2758 です。
- DB の表と列は DROP しません。コードの参照だけを外します。
- 目標ノートからの移し替えは、本番のデータで移行が済んでいるかを確かめてから消します（#2757 の「着手前に決めること・確かめること」）。
- AI のカスタマイズを消すかは、まだ決まっていません。
