# D-20260607-main-1: UI 部品の集約先を `shared/` にするか配布形態ごとに持つか

> 出自: キュー原文なし — CLAUDE.md §6 のインライン注記と `coding-principles.md` §6「W0 で確定 = 案 A」から再構成（2026-08-09 バックフィル）。

## 背景

クロスプラットフォーム移行（Web / Electron / Capacitor）で UI をどこまで共通化するかを、W-parity ロードマップの土台タスク W0 で決めた。当時は Tauri 時代の renderer（`frontend/`）と `shared/` に部品が二重に存在していた。

## 選択肢と裁定

- 案 A: 部品（デザインシステム）・`lumen-*` トークン・i18n（en/ja catalog + i18next singleton）をすべて `shared/` に集約し、3 配布形態が同じソースを共用する（**採用** — 2026-06-07 W0 で確定）
- 案 B: 配布形態ごとに UI を持つ（却下 — 同じ画面を 3 回直すことになり、面ごとの差が固定化する）

## 波及

- CLAUDE.md §6「新規 UI は `shared/src/components/` に集約」/ `docs/vision/coding-principles.md` §6
- 旧 `frontend/` の削除（2026-07-11 #197・復元は git tag `pre-tauri-removal`）
