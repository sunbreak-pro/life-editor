# D-20260902-sched-1: 「本日分の Todo」から「その他」へ移した Todo の日付をどうするか（#1406）

## 背景

（キュー原文 — 回答に伴い本 PR でキューから削除。起票 = chat-schedule-refine / PR #1463）

- 背景: #1406 で「本日分 / その他」の 2 分類にし、ホバー操作で行き来できるようにした。Todo の時刻は `scheduledAt`（日付 + 時刻の 1 つの瞬間）の中にあるので、「日付だけ外して時刻は残す」が保存できない。「その他 → 本日分」は日付だけを今日に変えて時刻を保つ（Issue の指定どおり・実装済み）。逆方向だけが割れる（`web/src/schedule/todoChipUndoWiring.ts::todoMoveOutWrite`）
- 放置時: A のまま（現行 PR の挙動）
- 期限感: いつでも

## 選択肢と裁定

- A: 日付を外して未配置に戻す（時刻も消える。Undo で戻せる）（**採用** — ユーザー回答 2026-09-05 AskUserQuestion。旧「Todo から追加」の逆操作と対称で、勝手な日付を発明しない。PR #1463 の実装がこれ）
- B: 翌日へ送る（時刻を保つ。「その他」に翌日の行として残る）（却下 — 移動先の日付を実装側が決めることになり、翌日に何かある人には「予定が勝手に動いた」と見える）

## 波及

- 実装 = PR #1463（`todoMoveOutWrite` = `scheduledAt` / `scheduledEndAt` を外し `isAllDay: false`、Undo ラベル `todoRemoveFromToday`）。追加 PR 不要
