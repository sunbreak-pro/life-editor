# D-20260922-work-1: リロード後にタイマーの走行状態を復元するか

## 背景

（キュー原文 — 回答に伴い本 PR でキューから削除。起票 = chat-work-refine）

- #1857 / PR #1909。リロードで残る `timer_sessions` の行は、次の起動時に閉じるようにした。タイマー自体は今までどおり停止状態に戻り、選択中の作業名とセッションドットも消える。復元するなら、フェーズ・開始時刻・経過・作業名を localStorage に持ち、起動時に続きから走らせる
- 放置時: A（復元しない）。#1857 は PR #1909 の範囲で閉じる
- 期限感: いつでも

## 選択肢と裁定

- A: 復元しない。記録は欠けなくなったので実害は「もう一度 Start を押す」だけ。復元は「離席中に完了時刻を過ぎていたらどう扱うか」「別タブで同時に開いたらどちらが走るか」の分岐を連れてくる（**採用** — ユーザー回答 2026-09-23）
- B: 復元する（却下）

## 却下案が復活する条件

リロードや自動更新でタイマーが止まる頻度が高く、記録の欠落ではなく「集中が切れる」実害が出たとき。
