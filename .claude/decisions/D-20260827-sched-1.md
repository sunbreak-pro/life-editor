# D-20260827-sched-1: narrow の日リストを畳んだあと、作成導線をどこに置くか

## 背景

#1148（2026-08-27 ユーザー確定）が narrow のメイン画面から「月グリッド下の日リスト」を撤去する。その日リストの見出し行には `<AddPill>` があり、**それが狭幅で予定を作る唯一の導線**だった（#1034 が #632 の浮いた FAB を畳んでここへ移した）。リストごと消すと作成導線が消える。

Issue が A / B の 2 案と推奨（A）を提示していたため、キューには積まず推奨案を採った。B を採る場合は #1034 の判断を覆すことになり、それは Issue の想定外だったため。

## 選択肢と裁定

- **A: サイドバー「今日の流れ」タブの見出し行へ `<AddPill>` を移す（採用）**。#1034 の理屈がそのまま持ち越せる — 作成ボタンは**スクローラの外に固定された見出し**に置く、浮かせない。移設先の見出し行は「その日のラベル + 完了数」であり、narrow ではその日が選択日に追従するので、「この日に足す」の意味も保たれる
- B: FAB を復活させる（#632 の形）（却下 — #1034 の判断を覆す。浮いた「+」は最後の行を覆い、その回避に `pb-24` の空き帯が要るという、#1034 が消したばかりのコストがそのまま戻る）

## 波及

- Desktop は 1px も動かさない: ピルはホストが `isWide` で出し分け、狭幅にだけ渡す（Desktop はツールバーの「+ 追加」を既に持つ）
- `web/tests/scheduleNarrowAdd.test.ts` の近接アサーションが `CalendarNarrowLayout.tsx` から `ScheduleSidebar.tsx` へ移る。あわせて「レイアウト側に `AddPill` が戻っていないこと」を新しく固定した — ピルの再出現は日リストの復活か、裁定に無い 2 本目の作成導線を意味するため
- 見た目の最終確認（ピルが見出し行で窮屈でないか）は merge 後にこうだいさんの手番

## 却下案が復活する条件

- サイドバーを開かずに作成したい、という要求が実測で出たとき（今の形では作成に 1 タップ増えるため）
