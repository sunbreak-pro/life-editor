# D-20260818-sched-3: #1000「カレンダー上の Todo チップ」は日リストの行か、月グリッドのドットか

## 背景

（キュー原文 = `comm/decisions/chat-schedule-refine.md`）

- #1000 が求める narrow の Todo 詳細シートは**既に存在する**（#761 が #626 の上に着地済み）。ただし narrow のカレンダーに Todo「チップ」は無い — #878 以降、狭幅の月グリッドは `size-1.5`（6px）の非対話な `<span>` のドットを描くだけで、タップできる Todo 行はその下の日リストにある
- A: 日リストの行のこと（推奨・#1000 は解決済みとして close）
- B: 月グリッドのドットのこと → 別の仕事（6px は `TAP_TARGET` 44px 下限に対して桁違いに小さい・Desktop も描く共通部品）
- 期限感: #1095 の merge 前まで

## 選択肢と裁定

- A: **日リストの行のこと**（**採用** — ユーザー回答 2026-08-19）。理由: 求めていた面は #761 で着地済みで、PR #1095 がその経路をテストで固定した。#1000 は解決済みとして close
- B: 月グリッドのドット（却下 — タップ下限 44px に対し 6px は桁違いで、ドット行の下に日付選択ボタンがあるため stopPropagation も要る。さらに Desktop も描く共通部品なので「Desktop 不変」が無料でなくなる）

## 却下案が復活する条件

- 月グリッドそのものを対話可能にする別 Issue が立ったとき（そのときはタップ領域の設計から始める）
