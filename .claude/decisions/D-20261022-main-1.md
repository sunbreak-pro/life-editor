# D-20261022-main-1: life-editor を配布するか、作者だけの個人の道具にするか

## 背景

（キュー原文はありません。2026-10-22 に main チャットでこうだいさんが直接答えた裁定を、その指示文から再構成した事後記録です。キューを通っていないため、status は recorded にしました）

D-20260829-main-1 で、方針を「限定人数（無料枠の安全圏 10〜20 人）への配布 + サインアップ開放」に変えていました。その後、配布を続けるか、作者本人だけが使う道具に戻すかを決め直す必要が出ました。あわせて、公開リポジトリにライセンスが無い状態を解消する必要がありました。

## 選択肢と裁定

- A: 作者本人だけが使う個人の道具にする（**採用** — 2026-10-22 ユーザー裁定）。他人への配布とサインアップの開放はしません。リポジトリは参考のために公開したままにし、ライセンスは All rights reserved にします（`LICENSE` は #2353 で追加）。
  - 理由: 作者は会社に勤めていて、少なくとも 3 年は副業ができません。製品として市場に出す価値は低いと判断しました。このアプリの価値は、個人の道具としての価値にあります。
- B: 限定人数への配布を続ける（却下 — A の理由により、配布を続ける意味がありません）

## 波及

- `.claude/CLAUDE.md` §1 の配布方針の行を書き換え、Non-Goals に「他人への配布」を足しました。
- `README.md` に、個人の道具で外部からの Issue と PR は受け付けないと書きました。`LICENSE` の追加と、ルートの `package.json` の `description` の更新も同じ #2353 です。
- コードは変えません。サインアップ・メール確認・法的ページ・アカウント削除など、配布向けに作った機能はそのまま残します。
- `.claude/CLAUDE.md` §2 の Cloud Sync の行と、`docs/vision/core.md` 冒頭の反転点ブロックも、同じ #2353 でこの裁定に合わせました。
