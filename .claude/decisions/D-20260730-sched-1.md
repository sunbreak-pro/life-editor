# D-20260730-sched-1: 編集パネルで日付を変えたとき、カレンダーを移動先の日へ飛ばすか

## 背景

（キュー原文 = `comm/decisions/chat-schedule-refine.md`）

#469 で編集パネルに日付ピッカーを付けた。日付を変えると、その行は今表示している週から外れて見えなくなる。

## 選択肢と裁定

- A: **飛ばさない**（**採用** — ユーザー回答 2026-08-12。現行実装の追認）。カレンダーは今の週のまま。エディタは開いたままで、日付欄が新しい日を表示する。行がグリッドから消えるのは次の同期後
  - 利点: 壊れない。飛ばす実装（#484 初版）は、可視範囲が変わると再フェッチが `rangeItems` を置き換えて**保存が着地する前の楽観更新を捨てる**ため、行がどこにも無い瞬間に詳細パネルが自分で閉じた（QA の Blocking B-2）
  - 欠点: 移動先を目で確認できない（日付欄の数字で確認するしかない）
- B: 飛ばす（保存の着地を待ってから）。`updateScheduleItem` を await 可能にして、DB に着いてから anchor を動かす（却下 — 移動先は見えるが、`useScheduleItemsAPI` の書き込み API を await 可能にする改修（現状 void の fire-and-forget）と失敗時の toast 設計が要る）

## 却下案が復活する条件

「移動先を目で見たい」という要望が実際に出たとき。その時点で B を Issue 化して実装する。
