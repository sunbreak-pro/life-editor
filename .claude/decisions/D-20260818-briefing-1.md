# D-20260818-briefing-1: 夕刊のフォーカス入力欄の見出しを「明日のフォーカス」にしてよいか

## 背景

（キュー原文 = `comm/decisions/chat-briefing-refine.md`）

- #1048 の DoD は「夕刊に『今日のフォーカス』の入力欄」だが、夕刊で書いた内容は**翌朝**の朝刊が「今日のフォーカス」として表示する。夕刊の時点では明日の話なので、Issue の字面どおりにすると「今日＝もう終わる日」と読めて逆向きになる
- A: 夕刊側は「明日のフォーカス」（en: TOMORROW'S FOCUS）、朝刊側は従来どおり「今日のフォーカス」（推奨・実装済み）
- B: 夕刊側も「今日のフォーカス」（名前は揃うが指す日がずれる）

## 選択肢と裁定

- A: **夕刊 = 「明日のフォーカス」**（**採用** — ユーザー回答 2026-08-19）。理由: 書く晩と読む朝で指す日が一致する。ラベルの一致より、指す対象の一致を優先
- B: Issue の字面どおり（却下 — 名前は揃うが、晩に「今日」と書かせると終わる日の話に読める）

## 波及

- なし（#1048 = A で着地済み）
