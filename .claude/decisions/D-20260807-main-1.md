# D-20260807-main-1: スマホからの主導線をネイティブ殻にするか公開 Web URL にするか（#600）

> 出自: キュー原文なし — CLAUDE.md §2 のインライン注記（「#600・2026-08-07 ユーザー確定」）と #600 の計画書から再構成（2026-08-09 バックフィル）。

## 背景

モバイル UI は画面幅（`useMediaQuery`）で切り替わるため、ブラウザで開けば Capacitor 殻と同じ画面が出る。一方でネイティブ殻は署名・配布の手間が要り、$0 制約のもとでは更新のたびに再配布が必要になる。

## 選択肢と裁定

- **採用**: スマホからの主導線は**公開 Web URL**（Cloudflare Workers Static Assets・$0）。ネイティブ殻は廃止せず併存させる
- 却下: Capacitor 殻を主導線にする（配布・署名のコストが更新のたびにかかり、iOS は特に重い）

## 波及

- CLAUDE.md §2 の主導線宣言・移行 SSOT §5-B（Web URL 公開は 2026-08-09 に着地）
- PWA の採用範囲・配布経路は移行 SSOT §8 / §9 で継続審議
