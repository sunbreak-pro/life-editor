## 実装の着地（2026-08-12 実測 — Epic #716）

閉じるボタンは `BottomSheet` 本体に**無条件で**入っている（Issue #525 / PR #539）。個別シートのオプトインではないため、閉じ道の無いシートは構築できない。

- ボタン = `shared/src/components/BottomSheet.tsx:115-128` — ヘッダ行に常設。`size-11`（44px）で、`aria-label` は必須 prop の `closeLabel`
- 型で強制 = `shared/src/components/BottomSheet.tsx:19` — `closeLabel: string` を optional にしていない（読み上げ名の無い唯一の出口を型で塞ぐ）
- 全シートが本体経由 = `QuickAddSheet` / `PomodoroTaskSheet` / `GraphSettingsSheet` / `QuickCaptureSheet` はいずれも `BottomSheet` を包む形で、独自の殻を持たない
- 守り = `shared/tests/bottomSheetDismiss.test.tsx`
