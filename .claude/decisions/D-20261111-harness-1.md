# D-20261111-harness-1: CLAUDE.md の「経緯の記述」に限って、移行完了を待たずに先に移すか

- 背景: `.claude/CLAUDE.md` の移送（layering Phase 3）は、D-20260806-main-3 = A で「移行完了後」に止めてある。その間に CLAUDE.md は 5,357 tok（2026-08-06）から 9,882 tok（2026-11-11）へ、3 か月で 1.84 倍になった。行数は 145 行で「150 行目標」を守れていて、増えたのは 1 行の長さである。決定の日付・Issue 番号・退役の経緯が、既存の行の括弧の中に足されてきた。計測と節ごとの内訳 = `docs/vision/plans/2026-11-11-claude-md-history-offload.md` の Context

- B: 移行完了まで待つ（D-20260806-main-3 のまま。待つ間も増え続ける）
- C: 関門を外して Phase 3 を全部いま行う（移行で動く節は、移行のあとにもう一度直すことになる）
- 放置時: 何も変えない（B と同じ）
- 期限感: いつでも
