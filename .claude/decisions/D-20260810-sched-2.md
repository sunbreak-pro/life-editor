# D-20260810-sched-2: #625 変換で id を維持するか、新規作成するか

## 背景

#625（Event ↔ Todo 相互変換）。`items_meta` + payload の 2 行分割モデルのため、role の付け替えは「旧 payload 削除 → `items_meta.role` UPDATE → 新 payload INSERT」の 3 手が要る（db-conventions §10）。

## 選択肢と裁定

- A: **id 維持**。3 手を 1 トランザクションで通す。（**採用** — ユーザー回答 2026-08-10。WikiTag / Link は role 区別なしで `items_meta.id` を参照するので、タグとリンクが無傷で残る。DataService にトランザクション実装が要り、失敗時の孤児回収は db-conventions §10 R2 に厳密に従う）
- B: 新規作成 + 旧行ソフトデリート。（却下 — タグ / リンクの移送を自前で書く必要があり、Trash に旧行が残って紛らわしい）
