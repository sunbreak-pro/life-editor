# D-20260731-sched-3: 台帳フィルタをタスクチップにも効かせるか

## 背景

（キュー原文 = `comm/decisions/chat-schedule-refine.md`）

#468 の初版はカレンダーを選んでも青いタスクチップが残る（合流点が絞り込みの後段のため）。QA の指摘で判明。タスクも `TagPicker` で同じ life-tag を持てる（`web/src/tasks/KanbanView.tsx:436`）ので、「タグは持てないから対象外」という説明は成立しない。

## 選択肢と裁定

- A: **タスクチップにも効かせる**（**採用** — ユーザー回答 2026-08-12。現行実装の追認）。`hiddenByCalendar` に合算する
  - 利点: 「Work を選んだのに Home のタスクが並んでいる」が消える。チップの数字と画面上のブロック数が一致する
  - 欠点: Schedule の Todo トレイと見え方がずれる瞬間がある（トレイ側は非適用のまま）
- B: 予定だけに効かせ、その旨を明記する（却下 — Issue の文面「どの予定をいま見るか」には忠実だが、画面上は絞り込みが半分しか効いていないように見える）
