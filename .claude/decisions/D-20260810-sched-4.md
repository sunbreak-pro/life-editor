# D-20260810-sched-4: #625 Todo → Event のステータスと親子関係の扱い

## 背景

#625。Event にはステータス（未着手 / 進行中 / 完了）と親子関係に対応する行が無い。

## 選択肢と裁定

- A: **ステータスは破棄（変換ダイアログで明示）・子を持つ Todo の変換は禁止**（変換を止めて理由を表示）。（**採用** — ユーザー回答 2026-08-10。「子だけ取り残される / 子ごと Event 化する」という難問を回避できる。子持ちを特別扱いする路線は #573 の削除ガードとも一貫）
- B: 子持ちも許可し、子は Todo のまま残す（親リンクだけ外す）。（却下 — 子が孤児化して Tasks 画面のツリーが崩れる。「親を変換したら子がバラけた」は事故に見える）
