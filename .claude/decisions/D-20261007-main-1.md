# D-20261007-main-1: 外側に作る拡張アプリを NG-3 の例外として認め、V3 の「家計簿は汎用 Database で表す」を拡張アプリに置き換えるか

## 背景（キュー原文）

- 背景: Issue #2127 / 計画書 `2026-10-07-extension-app-gateway.md`。NG-3 は「特定用途特化アプリの直接実装はしない（家計簿専用 UI などは汎用 Database で実現）」（`.claude/docs/vision/core.md` §4）。V3 も家計簿を汎用 Database の例にしている（`core.md` §3）。拡張アプリは別リポジトリに作り、life-editor 本体には専用 UI を作らない。汎用 Database は凍結中（D-20260704-main-1）。
- A: NG-3 を「life-editor 本体に専用 UI を作らない」ことと明確にし、外側の拡張アプリは NG-3 に反しないと読む。V3 の家計簿の例は「拡張アプリで表す」に置き換える。汎用 Database は凍結のまま解凍しない（推奨 — 本体の方針を変えずに、こうだいさんの 2026-10-06 の決定と矛盾しない）
- B: NG-3 は文面のまま残し、拡張アプリは例外として 1 件ずつこうだいさんが承認する。V3 は変えない
- 放置時: 計画書は Draft のまま、窓口の実装に着手しない（Step 1 で止まる）
- 期限感: 窓口の着手前まで

## 裁定

A（**採用** — ユーザー回答 2026-10-07、チャットの選択式の質問）: NG-3 を「life-editor 本体に専用 UI を作らない」と明確にし、外側の拡張アプリは NG-3 に反しないと読む。V3 の家計簿の例は拡張アプリに置き換える。汎用 Database は凍結のまま。
