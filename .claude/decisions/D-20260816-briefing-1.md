# D-20260816-briefing-1: 週開始曜日を切り替えたとき、今週の目標をどう扱うか

## 背景

（キュー原文 = `comm/decisions/chat-briefing-refine.md`）

- #957（PR #973）で目標を期間キー付きにした。週のキーは**その週の開始日**（`startOfWeekKey(todayKey, weekStartsOn)`）なので、`useWeekStartPref` を日曜始まり ⇄ 月曜始まりで切り替えるとキーが 1 日ずれ、**書いたばかりの今週の目標が履歴側へ回って欄が空になる**（本文には残るので消失ではなく「見えなくなる」）。実測: 現状 `useWeekStartPref` に Settings の書き込み UI は無く、手で localStorage を触ったときだけ起きる
- A: 現状維持 = キー完全一致のみ（推奨）
- B: 今週の範囲に入る週セクションを拾って採用する

## 選択肢と裁定

- C: **週開始曜日の切替そのものを廃止し、すべて日曜始まりに統一する**（**採用** — ユーザー回答 2026-08-19。提示した A / B ではなく、前提を畳む第 3 の道をユーザーが指定）。理由: 切替が無ければキーはずれず、この問い自体が消える。実測でも `useWeekStartPref` に書き込み UI は無く、既定は既に日曜（`DEFAULT_WEEK_START = 0`）。「誰も切り替えられないのに、切り替えられる前提の配線だけが 15 ファイルに通っている」状態を畳む
- A: キー完全一致のみ（不採用 — C が入れば問題が消えるため、判定規則の議論自体が不要になる）
- B: 範囲で拾う（却下 — 「一致」と「範囲」の 2 種類の判定が並び、範囲内に 2 つあったときの規則も要る）

## 却下案が復活する条件

- 週開始曜日を選びたいという要望が改めて出たとき。そのときは切替の復活とセットで A / B のどちらかを決める必要がある

## 波及

- 実装 Issue **#1102** を起票（`useWeekStartPref` の利用撤去・`life-editor-week-start` の読み書き廃止・日曜固定）
- **`D-20260813-briefing-1` の「週の開始曜日は既存の `useWeekStartPref` に従い、月曜固定にしない」を supersede する**（暦週へ寄せる方針自体は維持。始まりが日曜で固定されるだけ）
