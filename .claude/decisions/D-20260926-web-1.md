# D-20260926-web-1: 確認メールの送信サービスと送信ドメインをどうするか

## 背景

（キュー原文 — 回答に伴い本 PR でキューから削除。2026-09-28 に chat-main が回答を転記・昇格した）

- 背景: #1986（PR #1999）。調べたどのサービスも、確実に届けるには DNS を編集できる自分のドメインが要る。今の公開 URL `life-editor.sunbreak-pro.workers.dev` は Cloudflare のドメインで SPF / DKIM を足せない。`@gmail.com` を差出人にすると Gmail / Yahoo の DMARC で弾かれるか迷惑メールに入る。無料枠は Resend = 1 日 100 通・月 3,000 通、Brevo = 1 日 300 通で、どちらも永年無料・カード不要・Supabase の公式一覧に載っている
- A: Resend + こうだいさんが持っている（または用意する）ドメインのサブドメイン（推奨 — SMTP 設定がいちばん単純で、配布 10〜20 人なら 1 日 100 通で足りる）
- B: Brevo + 同じくドメイン（1 日 300 通と枠が広い。無料枠のメールには Brevo のロゴが付く）
- C: Brevo + gmail アドレスの単独差出人（ドメイン不要で $0 のままだが、届かない可能性が高いので非推奨）
- 放置時: 内蔵 SMTP のままにし、配布ユーザーのサインアップ受け入れを保留する
- 期限感: 配布開始の前まで。ドメインを新しく買う場合は年額の費用がかかり、「完成までコスト $0」の例外になる

## 選択肢と裁定

- A: Resend + 自分のドメインのサブドメイン（今回は見送り — 推奨はこれだったが、ドメインが要る。C で届かなかったときの切り替え先として残す）
- B: Brevo + 自分のドメイン（今回は見送り — A と同じくドメインが要る。C で届かなかったときの切り替え先として残す）
- C: Brevo + Gmail アドレスの単独差出人（**まず試す** — ユーザー回答 2026-09-28「最初に Gmail で確認する」。ドメイン不要で $0 のまま始められるため、先にこの形で届き方を実測する）

解釈の仮定: 「Gmail で確認する」を、送信元に Gmail アドレスを使う案 C の試行と読んだ。

## 却下案が復活する条件

- Gmail 以外の受信側（Yahoo など）で確認メールが弾かれる、または迷惑メールに入る場合は、A / B（自分のドメイン）への切り替えを再判断する。その判断は新しい D ファイルで記録し、本ファイルと supersede で結ぶ
- A / B でドメインを新しく買う場合は年額の費用がかかり、「完成までコスト $0」の例外になる

## 波及

- #1986 の作業は C の手順（Brevo のアカウント作成・Gmail アドレスの単独差出人の認証・Supabase の SMTP 設定）で進める。ダッシュボードと Brevo の設定はユーザーの作業
- 届き方の実測（Gmail 以外の受信箱を含む）を、配布開始の前に済ませる
