# D-20261006-main-1: Claude カスタマイズ（ルール / メモリ / テンプレート）の保存・反映・書き戻しをどうするか

## 背景

親 Epic #2117。Life Editor の中で Claude Code に渡す「ルール（CLAUDE.md 相当）」「メモリ（覚えておいてほしいこと）」「テンプレート（SKILL.md 相当）」を編集・保存できるようにする。要件（2026-10-06 ユーザー確定）:

- Mobile / Desktop の両方で制限なく編集・保存できる（SSOT = DB・Supabase 同期）
- Mobile は編集・保存まで。遠隔起動は対象外
- Desktop は Claude Code を起動し、保存内容を効かせて作業させる。Claude が作ったテンプレートや記録は Life Editor に戻す

着手前に 4 問をユーザーに確認した。

## 選択肢と裁定

**Q1. Claude が作ったテンプレート・記録の書き戻し経路**

- A: **life-editor の MCP サーバーにツールを足し、DB に直接書く**（**採用** — Mobile に即同期される。DB が唯一の正本のまま保てる）
- B: Claude が作業フォルダに書いたファイルを、次回起動時にアプリが取り込む（却下 — 反映が次の起動まで遅れ、ファイルと DB の二重管理になる）
- C: A + B の両方（却下 — 取り込み時の衝突解決が要る。必要になってから足す）

**Q2. ルール（CLAUDE.md 相当）とメモリの効かせ方**

- A: `--append-system-prompt-file` で渡す（提案時の推奨。却下 — ユーザーはテンプレートと同じ置き場にまとめることを選んだ）
- B: 作業フォルダ（ユーザーのリポジトリ）に CLAUDE.md を書く（却下 — 既存 CLAUDE.md と衝突する）
- C: `~/.claude/CLAUDE.md` に書く（却下 — アプリ外で起動した Claude Code にも効いてしまう）
- D: **テンプレートと同じアプリ専用フォルダに `.claude/CLAUDE.md` として置く**（**採用** — ユーザー回答。ルール・メモリ・テンプレートが 1 か所にまとまる）

**Q3. テンプレート（SKILL.md）の書き出し先**

- A: **アプリ専用フォルダの `.claude/skills/<slug>/SKILL.md` に書き出し、`--add-dir <アプリ専用フォルダ>` で読ませる**（**採用** — アプリから起動したときだけ効き、ユーザーのリポジトリを汚さない）
- B: 作業フォルダの `.claude/skills/`（却下 — git に混ざる）
- C: `~/.claude/skills/`（却下 — アプリ外の起動にも常に出る）

**Q4. メモリの形**

- A: **1 件ずつの項目リスト**（**採用** — Claude の追記・個別削除がしやすく、Mobile でも編集しやすい）
- B: 1 枚の自由テキスト（却下 — Claude の追記のたびに全体の書き換えが起きやすい）

## 技術的な前提（裁定の成立条件）

- Claude Code は `--add-dir` で足したフォルダの CLAUDE.md を**既定では読まない**。環境変数 `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` を立てると、そのフォルダの `CLAUDE.md` / `.claude/CLAUDE.md` / `.claude/rules/*.md` を読む（公式 docs: https://code.claude.com/docs/en/memory#load-from-additional-directories ）。起動時にこの変数を子プロセスの環境に入れる
- macOS の `open -a Terminal` 経路は spawn 時の環境を引き継がないため、起動スクリプト内で変数を設定する
- `--add-dir` のフォルダにある `.claude/skills/` はスキルとして読まれる（公式 docs: https://code.claude.com/docs/en/skills ）
- メモリ項目は `.claude/CLAUDE.md` に連結するか `.claude/rules/memory.md` に分けるかを #2120 の実装で決める（どちらも上の変数で読まれる）

## D-20260831-settings-1 との関係

同決定の Q2「プロンプトは渡さず素の `claude` を起動」は**維持する**。本決定でもユーザーが書いた文字列はコマンドラインに乗らない — コマンドラインに増えるのはアプリが決めた専用フォルダのパス（`--add-dir`）と固定の環境変数だけで、ユーザーの文章はファイルの中身として渡る。よって supersede ではなく拡張として扱う。

## 却下案が復活する条件

- Q1-B / Q1-C: Claude がツールを使わずファイルに直接書いてしまう事例が繰り返し出たら
- Q2-A: `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD` が廃止・挙動変更されたら
- Q3-C: アプリ外で起動した Claude Code でも同じテンプレートを使いたくなったら

## 波及

- #2118: メモリは 1 件 1 行のテーブル（項目リスト）で持つ
- #2120: 書き出し先 = アプリ専用フォルダの `.claude/CLAUDE.md` と `.claude/skills/`。起動引数に `--add-dir <専用フォルダ>`、環境に `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1`
- #2121: 書き戻しは MCP ツール（ローカル版・Remote 版の両方）
