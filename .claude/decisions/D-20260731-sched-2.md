# D-20260731-sched-2: #468 の台帳フィルタに「予定へタグを付ける導線」を同梱するか

## 背景

（キュー原文 = `comm/decisions/chat-schedule-refine.md`）

#468 でカレンダー台帳をグリッドのフィルタとして配線する。ところが実測したところ、**アプリ内に予定（event）へ life-tag を付ける導線が存在しない**（`assignTagToItem` の呼び出し元は Notes 詳細とタスク Kanban の TagPicker だけ・Schedule のコンテキストメニューの「タグを追加」は stub）。このままフィルタだけ入れると、カレンダーを選んだ瞬間に予定が全部消えてタスクチップだけ残る。

## 選択肢と裁定

- A: **同梱する**（**採用** — ユーザー回答 2026-08-12。実装済みの形を追認）。編集パネル（`EventEditorPane`）に `tagSlot` prop を 1 本足し、既存 `TagPicker` を注入するだけの最小追加。繰り返し由来の行は `routineId` を対象にして系列単位で付ける
  - 利点: #468 の DoD 1 番目「台帳の選択でグリッドが絞り込める」を予定について実証できる。差分は slot prop 1 本 + 注入 1 行
  - 欠点: #468 の差分が編集パネルにも伸びる（#467 の Mobile 領域とは別ブランチなので衝突はしない見込み）
- B: フィルタだけ先に出し、予定のタグ導線は別 Issue に切る（却下 — 差分は shared/utils + Desktop ツールバー + 台帳モーダルに閉じるが、台帳フィルタが実質タスク専用のまま出て「配線したのに効かない」が 1 PR 続く）
