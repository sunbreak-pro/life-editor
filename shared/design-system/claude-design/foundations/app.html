このアプリは何か

  • AI と会話しながら生活を設計・記録・運用するパーソナル OS である。
  • 予定・Todo・ノート・日記・集中作業を 1 つのアプリにまとめる。
  • Claude Code が MCP Server 経由で同じデータを読み書きする。スマホの Claude アプリも Remote MCP でつながる。
  • 主ユーザーは作者本人で、macOS と iOS で使う。
  • 10〜20 人の限られた人数に配り、サインアップを開いている。各ユーザーは自分だけの空間を持ち、共有や権限管理は持たない。

Desktop と Mobile

  • 境目は 768px の 1 本だけである。各画面はこの幅で wide と narrow を切り替える。
  • Desktop（768px 以上）は左のサイドバーを持つ殻で、全機能を使える。
  • Mobile（768px 未満）は下部タブバーの殻で、役割は閲覧（Consumption）と素早い入力（Quick capture）に絞る。
  • Mobile は Desktop を縮めた画面として作らない。セクションは全部たどれるが、各セクションの中の機能を取捨する。
  • 下部バーは固定 4 枠で、残りのセクションと Undo / Redo・コマンドパレットは「その他」シートに入る。
Consumption は閲覧が主で、完了トグルや★のような 1 タップの更新は含む。Quick capture は新規作成と簡易入力だけを指す。
