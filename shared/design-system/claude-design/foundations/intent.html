Design Intent — why the system looks this way

朝刊・夕刊パレットが表すもの

Light = 朝刊（Asakan）生成りの紙 朝日の燈色（ひいろ）
Dark = 夕刊（Yukan）藍染めの夜空 月明かりの薄藍
  • 地は彩度を抑えた紙と夜空の色にして、主アクセントは各テーマに 1 色だけ置く。毎日長く読む画面なので、目を引く色を増やさない。
  • ライトは真っ白を避けて生成りにし、ダークは真っ黒を避けて藍の夜空にする。わずかな地色のほうが長く読んでも疲れないからである。
  • 主ボタンと選択状態は accent（燈色 / 薄藍）を使う。mint は chip・tag・肯定の差し色にとどめ、朱と琥珀は Briefing の紙面だけで使う。
  • ダークの accent は明るいので、その上の文字（on-accent）は白ではなく near-black にする。
正本: shared/design-system/PRINCIPLES.md §3.3-3.4 · shared/src/styles/tokens.css

主要な背景は不透明にする

  • ポップオーバー・メニュー・ダイアログ・カード・パネルの本体は、不透明なトークンで塗る。
  • 半透明にすると下の文字が透けて、本文のコントラストが落ちる。
  • 未定義の bg-lumen-* クラスは警告なく透明になる。色は tokens.css に定義してから使う。
  • 透明を許すのは hover・モーダルの backdrop・accent の薄塗り・枠線・disabled・影だけである。
  • 本体を bg-*/70 や backdrop-blur で塗らない。
正本: .claude/rules/frontend.md §デザイン規約 · PRINCIPLES.md §3.5

色は lumen-* トークンだけで書く

  • 部品は bg-lumen-* / text-lumen-* だけを使い、hex や bg-sky-500 を書かない。
  • テーマを切り替えると tokens.css の値が入れ替わるので、名前で参照した部品は両テーマに自動で追随する。
  • 状態やデータを表す色（status band・chart）はテーマで変えない。変えると意味がぶれるからである。
  • 入れ子の data-theme には追随しない。lumen-* は宣言した要素で値が決まる。部分的に別テーマで描くなら、tokens.css の [data-theme] エイリアス節に 1 行足す。
正本: .claude/rules/frontend.md §デザイン規約 · PRINCIPLES.md §2 / §3.1-3.2

UI の 4 状態

  • Loading は初回だけ skeleton か控えめな spinner を出す。画面全体をふさがない。
  • Empty は文脈に合った 1 行と、次にできる操作を出す。
  • Error は原因を 1 行で書き、リトライ操作を置く。スタックトレースは画面に出さない。
  • Idle はデータがある通常の表示で、hover や focus に応える。
  • 処理中の aria-busy は単独で立てず、目に見える手がかりと組にする。押せない（disabled）と動いている（busy）を同じ見た目にしない。
正本: .claude/skills/frontend-react-designer/references/ui-states.md §1 · frontend.md §デザイン規約

Mobile のタップ目標は 44px

  • 狭い幅では、呼び出し側で max-md:min-h-11 max-md:min-w-11 を足して当たり判定を広げる。
  • --spacing-lumen-tap-min は名前に反して 1.75rem で、幅による切り替えを持たない。これを上げると Desktop のアイコンボタンが全部太るので、このためには使わない。
  • 密な行は箱を太らせず、透明な ::after で縦だけ広げる。横には広がらないので、隣り合う 2 ボタンには使えない。
正本: .claude/rules/frontend.md §Gotchas

余白・アイコン・動きの段の使い分け

  • 余白の段（p-lumen-* / gap-lumen-*）は、chip・ボタン・行・カード・シートの内側だけに使う。ページの外周は gutter の組（px-lumen-gutter md:px-lumen-gutter-wide）と Tailwind の数値の段で取る。
  • 余白の段は 4px 刻みの px で、20px の段は意図して欠けている。部品の内側に 16px と 24px の間の余白が要らないからである。
  • アイコンの段は rem で、Settings の文字サイズに合わせて伸び縮みする。sm は全 lucide アイコンが持ち上げられる下限そのもので、md と lg はそこから 1.25 倍ずつ大きくなる。
  • 既存の size={N} はまだ段に移していない。Briefing と Work の作り直しで画面ごとに移す。
  • 動きは fast を hover・focus・小さな状態変化に、normal をパネル・シート・ドロワーの登場に、slow を全画面の遷移に使う。入るときは ease-out、出るときは ease-in にする。
  • 動きを減らす設定（OS か Settings）が有効なら、すべての長さが 0 に近くなる。
値そのものは Steps カード（steps.html）と tokens.css が持つ。このカードは使い分けだけを書き、各段の値は写さない。
